# 等一尾 · 月隐湾

单人休闲 3D 垂钓游戏。当前工程使用 Three.js、SolidJS 和 Vite，在浏览器运行。它按可持续维护的游戏项目管理：规格、实现、测试和完成清单随每次逻辑迭代同步更新。

## 运行与验证

需要 Node.js 与 npm。Windows 上双击仓库根目录的 `月隐湾启动器.exe`，会打开原生桌面启动器；游戏服务就绪后自动打开默认浏览器。首次使用时自动安装缺失依赖。窗口中可查看状态和日志，使用主按钮启动或停止游戏；再次启动成功也会自动打开浏览器。关闭游戏标签页不会停止服务；请在启动器中点“停止游戏”或关闭启动器窗口。不要直接双击 `src/index.html`；浏览器的 `file://` 模式无法加载游戏模块。

开发时也可在本仓库根目录执行：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`npm run dev` 启动开发服务器；`npm test` 运行 Node 单元与结构测试；`npm run build` 生成并校验 `build/`；`npm run preview` 预览发布构建。静态托管时以 `build/` 为站点根目录。技术栈已确认为 Three.js + SolidJS + Vite，单元测试使用 Node `node:test`；本项目不使用 Unity。

## 目录

| 路径 | 职责 |
| --- | --- |
| `src/` | 游戏源码、界面、Three.js 场景与样式；活动入口是 `src/index.html` 和 `src/app-final.js` |
| `src/data/` | 钓点、鱼种、装备、天气、鱼讯和音频资源清单 |
| `src/config/` | 存档标识、容量上限、时间与出行规则 |
| `public/assets/` | 发布时直接加载的模型、贴图、字体和音频 |
| `assets_pipeline/` | Blender 等美术生产源与预览，不是运行时资源 |
| `tests/` | 业务、几何、镜头、资源和界面行为测试 |
| `tools/` | 资源生成与构建校验脚本 |
| `docs/` | 规格、架构图和已实现功能清单 |
| `archive/legacy/` | 不再作为活动入口的历史代码与设计页面 |
| `build/` | 可重新生成的发布产物，不入 Git |

更多依赖关系、存档兼容约束与维护路线见 [项目架构](docs/ARCHITECTURE.md)。开始修改前先读 [文档入口](docs/README.md) 与 [项目规范](AGENTS.md)。

## 当前玩法范围

现有代码包含选点选饵、抛竿、读漂、提竿与搏鱼、钓获处理、个人手记、生态/线索进度、设备本地存档，以及三维海岸和交互水面。鱼篓、金币、出售和装备升级也存在于当前实现；它们与历史产品交接材料 `HANDOFF.md` 的方向相冲突，尚未作产品决策。本轮结构整理保持现有存档键 `moonwater-v1` 和玩法行为。

自动测试与构建覆盖逻辑和资源完整性。真实浏览器画面、移动端手感和性能仍需按 `HANDOFF.md` 的清单验收，不能仅凭自动测试宣称完成。
