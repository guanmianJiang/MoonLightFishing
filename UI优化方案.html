《等一尾 · 月隐湾》UI 优化方案

基于 dist/index.html、style.css、app.js 的现状诊断 · 不改动 3D 场景与玩法逻辑，只收敛 HUD / 对话框 / 信息架构

一句话结论：不是元素丑，是"每个元素都在抢主"。准备态屏幕上同时常驻约 18 个信息块，玻璃拟态铺了 7 层，强调色散成 5 个，圆角 8 种——结果水面（本该是主角）被一圈等权重的浮层围住，玩家不知道先看哪。优化方向是做减法 + 立 token：把分散的"本轮状态"收进一个面板，把玻璃只留给真正需要浮在场景上的层，把颜色/圆角/字号收成三档。

一、根因诊断

信息架构

同类信息散在五个角落

  • "轮次/剩余竿数/调查进度"在右上三 chip。
  • "天气/追踪/连续判断/本轮目标/水域事件"在左上第二行四 span。
  • "钓点/水深/状态文案/步骤"在底部 footer 四行。
  • "现场观察"在左下卡片。
  • 玩家视线要在 5 个区域间跳，且 chip 内容密度不一：有的装 1 个指标，有的塞 3 个（水域事件：…·已触发 N 次·…）。
视觉体系

没有 token，每个组件独立配色

  • 圆角 8 种：999 / 22 / 20 / 18 / 13 / 12 / 11 / 10 / 9。
  • 强调色 5 个：#e7c481、#df795a、#f3d79b、#e9a68e、#c7eee5；--sun:#d79760 定义了却几乎没用。
  • 阴影透明度从 .06 到 .33 随手写，没有 elevation 分层。
  • 玻璃拟态用在 header、spot、camera、bait-detail、toolbar、toast 共 6+ 处，浮层等于没有浮层。
  • 衬线体用在 story、h2、sceneAction、stepLabel、tactic strong 上，和无衬线按钮混排，节奏乱。
交互节奏

同一动作有三处入口

  • 读漂阶段：底部"提竿"、屏幕中央 #sceneAction 大圆、底部上方 #tactics 三按钮——三个 CTA 同时出现，视线来回跳。
  • footer 在 fishing/aiming 时 width 560→370，同时硬切隐藏 baits / separator / bait-detail / waterside，布局跳变。
  • 移动端 conditions 四 span 挤一行 truncate，"水域事件"直接被省略号吃掉。
  • toast 两套（toast / selectionNotice），样式几乎相同。

二、设计 token 收敛方案

把 style.css 里散落的数值收成 :root 变量，组件只引用变量，不再写死。

四、优先级清单

P0 · 立刻见效（半天）
  1. 把 :root 扩成 token 表（圆角/字号/阴影/色），全文件查找替换硬编码值。
  2. 右上 4 chip + conditions 4 span 合并为一个"本轮"胶囊：第2轮·剩3竿 · 进度 12，点击展开目标/事件/追踪。
  3. header chip、spot、camera、bait-detail 去掉 backdrop-blur，改实色 + --e1。
  4. 读漂阶段去掉中央 #sceneAction，提竿只保留底部主按钮 + 点浮漂两种操作。
P1 · 一周内（让节奏顺）
  1. footer 从 4 行压成 2 行：上行 status + 地点，下行 toolbar；fishing 态不缩 width，改 opacity 过渡。
  2. 左下"现场记录"从卡片改成单行文字（去掉左边框和渐变底），只在有新线索时短暂浮现。
  3. dialog 内卡片背景统一为 --soft:#e8eee7，book 四个 tab 不再各自配色。
  4. 合并两套 toast；移动端 conditions 改为纵向两行，不再 truncate。
P2 · 后续打磨
  1. 结果弹窗：specimen 图区和 stats 之间加留白分层，process 三按钮改为"保留/放流/记录"两主一次。
  2. book 的 collection / water / gear / clues 列表项抽成统一的 entry 组件，去掉重复样式。
  3. 加一个 prefers-reduced-motion 之外的"UI 简洁模式"：等待态自动隐藏 camera 和 hint。

本方案只动 dist/index.html / dist/style.css / app.js 里的 UI 渲染层，不碰 scene.js / water.js / fishing-motion.js 的 3D 与玩法。确认方向后我可以直接落地 P0。
