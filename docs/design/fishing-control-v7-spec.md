# 核心垂钓操作 V7：弹性与钓钩浮雕

状态：独立可交互设计，尚未接入游戏运行控件。日期：2026-10-01。

## 目标

玩家指出V6弹性不足，内部文字与细线竿图不搭。本版保留同一连续物体和全部四向/斜向手势，增强拉伸、按压和有限回摆；移除视觉动作文字，改为居中钓钩浮雕。遵守HANDOFF的欧卡休闲、干净温暖、轻操作与场景净空。没有机械盘、外置箭头、装饰图片或常驻状态仪表。

## 几何与反馈

- 9:16；右下区148×148，right20/bottom28；固定124×124事件节点，指针捕获后可滑出。图形层均pointer-events:none，不吞水面输入。
- 拖动偏压最大18px（V6为12px），原dx/dy映射0.375后等半径夹限。后缘锚定、前缘伸出；侧向截面随位移最多收紧5%，前/后端不做横向收缩。按压使表面纵向压缩2.5%、横向鼓起1.8%，顶面下沉4px，同色侧沿始终连接。
- 底部跟随形变0.15。表面、倒角、内面和投影共用64点周期三次曲线。静止7px、按压约3px厚度。暖杏色哑光面、浅宽倒角，不重建双色底块。
- 释放420ms阻尼弹簧：位移先回中，最多一次约12%的反向回摆，再收敛。归一化权重有界[-0.14,1]，终点精确0。回摆不作用于物理手势，不重新触发抬竿/让线。按压深度回归不取负；弹性来自几何形变和一次回摆，不永久晃动。
- 减少动态时直接回中；新触控立即接管，第二真实指针仍不得接管；cancel/blur/隐藏/状态变化立即取消回弹、演示和短事件。
- 保留一个贴合受力边缘的短弧：四向/斜向连续；机会只提示上沿、危险优先。真实accepted决定短确认，拒绝不假成功。

## 内部表达

- 取消视觉动作名和细线钓竿图。中心只有60×60钓钩浮雕：宽软轮廓、海盐绿本体、浅亮上沿和薄侧面，与按钮材质一致；不用字体图标或平台emoji。
- 符号随表面中心移动视觉位移的0.35并小幅侧倾，无独立按钮底板、绕圈或假机械运动。文字“收线/调竿/让线/抬竿”仅保留在aria-label和读屏状态；必要短纠错仍可在按钮上方瞬时出现。
- 无文字入口的初次发现性仍待新玩家测试；不能以这轮审阅代替教学验证。不能把正常状态句重新放回内部。

## 接口与输入输出

自包含源码在 `docs/design/prototypes/fishing-control-v7/`：`surface.mjs`、`control.template.html`、`control.css`、`hook.svg`、`scene.jpg`；生成片段为 `index.html`。构建/测试不依赖未提交旧样例或运行源码。

`fishingSurfaceGeometry({dx,dy,pressed,guide,risk})` 输出有界位移、中心、顶/底点、共用侧沿/内面/短弧路径、光照参数；NaN/Infinity回中、pressed夹限0–1。`fishingSurfaceReturn(progress)` 输出有限弹簧权重，起1终0。边缘风险优先，所有路径有限连续。

物理手势沿用既有门槛：dy<-42、|dx|≤30且机会允许抬竿；dy≥24让线；抬竿dy≥-12、让线dy≤10回中；一机会一次抬竿。弹簧RAF只更新展示，不能调用move/begin或改变物理、存档。
