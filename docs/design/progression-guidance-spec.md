# 水域推进与难度引导规格

## 目标

玩家在近岸反复垂钓时，应清楚知道下一片水域的解锁进度、怎样推进，以及何时可以直接前往。近水落点提供宽松练习，远水更容易遇到需要搏鱼的目标；两者都由玩家在抛竿前选择，不加战斗中的选项或强制难度档。

## 数据与规则

- 继续使用现有存档 `knowledge`、`log`、`spot`、`bait`、`pending`；不新增持久字段，不重置旧进度。`knowledge` 是做记录和完成目标获得的调查进度。
- `explorationProgress(save)` 为 `knowledge + min(3, floor(近岸钓获数 / 2)) + min(4, floor(栈桥钓获数 / 2))`。钓获数从已结算的 `log` 中按 `spot` 统计，空钩不计，单竿只计一次。近岸最多提供前往栈桥所需的 3 点熟悉度，栈桥最多再提供 4 点；原有调查进度仍可更早解锁。旧存档直接按既有钓获计算，不补发奖励、不改写存档。
- 栈桥和深水沿用现有解锁阈值 3 与 7。已解锁水域可自由往返；不因后续处理方式、轮次或鱼篓变化重新锁住。
- 近水落点比中段多 2 秒提竿窗口，常见轻型鱼的抽取权重提高，大型鱼权重降低；远水保持原提竿窗口，反向偏向大型目标。落点只影响下一次新抛竿，已有 `pending` 保留原结果和时间。难度由水域、鱼种和落点自然递进，不隐藏提高失败率。

## 界面与接口

- 准备态的路线卡优先显示“下一步”：待解锁时显示准确的探索进度和获取方式；水域开放后提供可点按的“前往栈桥/深水”；进入新水域后先建议近水熟悉鱼口，再提示远水挑战。卡片保留本轮目标与手记入口。进行中的抛竿不能切换钓点或触发新瞄准。
- `progressionGuide(save)` 返回展示标题、说明、阶段、进度以及下一步动作；动作只允许 `aim`、`spot`、`bait` 或 `book`，由界面入口执行。无效、缺失或旧存档按当前可用水域给保守建议，不抛异常。
- 水域标记与顶部进度显示同一个 `explorationProgress`，避免一处显示“已开放”、另一处仍显示“0/3”。手记继续区分调查进度和垂钓熟悉度。
- 水域标记写明入门、进阶、挑战；瞄准态按当前落点的近水/远水显示提竿宽容或鱼情倾向，触摸改点后提示随之更新，不把落点预览误认为已经抛竿。
- 路线卡的主按钮至少 44 像素触控高度；9:16 竖屏不遮挡浮漂、主要抛竿按钮或钓点标记。引导只在准备/俯瞰状态出现，读漂和搏鱼时退场。

## 边界与验证

- 空钩、重复处理同一结果、恢复已结算存档不得重复增加探索进度；`log` 缺失或无效条目按零处理。旧 `knowledge` 仍保留原作用。
- 校验无调查进度但反复钓获的旧存档可以解锁栈桥，单靠近岸钓获不能直接解锁深水；解锁后能通过卡片切换钓点；近水与远水的提竿窗口及鱼种倾向有差异。运行 `npm test`、`npm run build`，并在竖屏页面查看路线卡和可点击入口。
