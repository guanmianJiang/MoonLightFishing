# 第一竿体验规格

## 目标

全新存档的第一次抛竿先建立“我选了一处水、看见鱼口、自己提竿”的感受，再呈现探索进度。开场不加入强制教学弹窗、必中钓获或额外货币奖励；玩家仍能自由换饵、调整落点和错过鱼口。

## 数据与接口

- `src/opening-cast.mjs` 用现有 `casts`、`log`、`trip`、`waterTrail` 判断是否处于第一竿；不新增存档字段。新抛竿在 `pending.openingCast` 保存本次判定，刷新后的演出和提示保持一致。
- 默认的近岸麦粒第一竿使用浅水常见鱼池，仅包含银背鲫与细鳞白条；其他鱼饵保留其现有鱼池。首竿重量上限、等待区间和提竿宽限集中在 `src/config/fishing-tuning.mjs`。下一竿及已有 `pending` 保持原规则。
- `src/progression-guide.mjs` 在未完成第一竿时返回简短水面观察方向，后续恢复原探索路线。路线动作只进入瞄准，抛竿仍需玩家再次确认。

## 体验流程

1. 开场路线卡先邀请玩家选近水落点，隐藏本轮任务、数值进度和难度说明；鱼饵仍可更换。默认推荐落点偏向角色左侧前方，让 9:16 近景中的浮漂、鱼影与人物轮廓分开；仍须在有效近水区域内，玩家可在瞄准态手动调整。竖屏实画应确认浮漂不贴住握竿手且鱼影初现没有离开画幅。
2. 瞄准态保持角色、落点与水面同框；确认后约 7–9 秒出现自然鱼口。等待先有一段安静水面，再有局部变化；鱼影试探时允许玩家轻点浮漂做一次可选的轻提鱼饵，鱼影会回应，未操作仍正常咬钩。
3. 第一竿咬实时，鱼线绷紧、竿弯和右下触控区继续是主要信号；顶部仅出现一次短句，明确“按住右下提竿”。首竿基础提竿窗口延长到 16 秒，近水仍额外增加 2 秒，不显示倒计时。
4. 玩家钓获、失手或空钩后，返回现有结果处理和下一竿线索流程；不自动代替玩家处理钓获。首竿失手仍可留下只供下一竿追的鱼讯。

## 边界与异常

- 旧存档、第二竿、换饵的首竿、刷新中的未决抛竿均不改写既定随机结果和 `readyAt`。
- 首竿钓到银背鲫时限制为轻型个体，降低首次搏鱼的骤然负担；仍由现有搏鱼模拟决定成功或失败。
- 沉水物和稀有鱼不在默认近岸麦粒第一竿鱼池中；玩家自由换饵后的鱼池不受此限制。
- `pending.openingCast` 缺失时按普通抛竿显示，不迁移旧状态。

## 验证

用 Node `node:test` 验证首竿识别、鱼池、时长、重量、第二竿回归与刷新边界。浏览器检查 390×844 和 320×568 的开场、瞄准、等待、咬实、失手回流；真实手机仍需检查触控、音频和帧率。十分钟试玩重点观察玩家是否在第一次结果前理解何时提竿，以及第一次结果后能否主动说明下一竿想看什么。
