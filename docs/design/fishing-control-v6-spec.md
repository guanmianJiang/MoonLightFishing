# 核心垂钓操作 V6：连续受力表面

状态：独立交互设计草案，尚未接入运行游戏。日期：2026-10-01。

## 目标与参考

修复V5两块不同颜色方块相对滑动的割裂感，移除四个外置箭头，保留全部四向/斜向输入。控制入口是同一件杏色哑光圆角物体；侧沿与表面共用连续几何，方向由局部边缘受力和整体偏压表达。保持HANDOFF的温暖、干净、欧卡休闲风格与场景净空，不添加机械轮盘、装饰图、光效表演或新玩法。

参考：[Apple虚拟控制器](https://developer.apple.com/videos/play/wwdc2021/10081/)的统一输入反馈与图形位置表达、[Kenney UI Pack](https://kenney.nl/assets/ui-pack)的统一控件状态、[Material Design形态与运动研究](https://m3.material.io/blog/material-3-carousel-research-design)的连续形变。这里只借鉴结构和反馈，不复制整套视觉。尝试读取ShaderToy的Raymarching Primitives和IQ文章，但页面访问失败，不能把它们记为已审阅视觉或借用代码。

## 几何、材质与布局

- 9:16竖屏。右下操作区148×148，right20/bottom28；实际事件节点124×124，left12/top12，固定不动。捕获后允许滑出；所有展示层pointer-events:none。
- 无绿色方块底座，无外置箭头/十字/四颗按钮。主表面约120×108，四次超椭圆轮廓，64个边界采样点以周期三次曲线连接。固定中心(74,70)和下方接触区，视觉dx/dy以0.25缩放至12px圆内。
- 表面各点按与拖动方向的夹角分配偏压：后缘权重0、侧缘0.25、前缘1，使用连续平方权重。前缘伸出、后缘留在原位，中心图标只移动视觉位移的0.35，不把整张方块平移。
- 下方接触轮廓只跟随表面形变的0.15；同一组顶/底点由连续曲面侧沿连接，静止厚度7px、按住3px。表面、倒角、侧沿同属杏色系。不存在可独立滑出的另一个色块。
- 高光、内面、投影由相同几何计算；同一表面有浅宽倒角、轻底沿，避免粗双描边/金边/玻璃/深绿底板。按住压低，连续跟手；松手220ms有阻尼地回到原状。没有常态动画循环。
- 方向由一个贴合轮廓的短受力弧段表达，连续覆盖任意角度，包括斜向。常态无弧；真实抬竿机会只上沿出现短提示；危险弧和侧沿呈珊瑚色。弧段不是仪表/百分比/整圈，不显示正常状态句。
- 保留已有cast图标和单动作名，图标不另绘制。有效抬竿/提竿/收回短确认，拒绝保持原动作并短纠错。风险覆盖机会与确认，已松手/让线不反复要求松手。

## 数据结构与接口

纯几何模块：`docs/design/prototypes/fishing-control-surface.mjs`。

`fishingSurfaceGeometry({dx,dy,pressed,guide,risk})` 输入有限视觉原始位移、按压0–1、机会和风险；输出 `{offset, center, top, foot, inset, wallPath, facePath, innerPath, footPath, edgePath, edgeVisible, thickness, light}`。所有坐标有限，缺失/非有限坐标回中，压限0–1，位移等半径夹限；风险优先于上沿机会。

`fishingSurfaceReturn(progress)` 返回0–1的单调有界阻尼权重，起点1/终点0。样例按真实脚本begin/move/end更新手势，SVG展示用模块源码内嵌，测试核对二者一致，避免测试另一套实现。

物理输入保持原门槛：上划dy<-42且|dx|≤30与真实机会允许；下划dy≥24让线；抬竿dy≥-12、让线dy≤10回中；一机会只抬竿一次。视觉偏压/受力弧不能自行产生accepted，不改变存档/鱼距/物理。

## 异常、边界与性能

第二指针忽略。cancel/lostcapture/blur/页面隐藏/状态变化取消手势、回放、回弹和短事件；重新按下立即接管回弹。减少动态时直接回中。风险在释放后保持；取消清除短成功，不给假动作。

只更新一个小SVG内的有限曲线路径，不新增WebGL上下文、纹理、shader或3D draw call。几何每次64点，触控跟手同步，释放仅220ms RAF，演示单次7秒，空闲无RAF。正式接入需低端手机检查路径更新帧时间与指针延迟，不能以Node耗时代替移动端性能。

## 验收与范围

测试正常/机会/风险、四向/斜向连续、原门槛与回中、后缘锚定、前缘形变、共用侧沿端点、路径无自交、同色表面、无箭头/底座、取消/隐藏/回弹接管、减少动态、有限值、窄屏边界。可从同一几何模块输出SVG供离线资源渲染检查，不能把它当浏览器实画或触控验收。
