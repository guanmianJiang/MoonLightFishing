# 通用按钮状态统一

日期：2026-10-01。依据HANDOFF的温暖欧卡休闲基调、coastal-ui及V7核心操作规格。范围：默认/hover/按压/选中/禁用/焦点；用户明确要求不进入游戏验证。

## 目标与边界

统一游戏工具、镜头、选饵/钓点、主操作、钓获选择、手记页签/关闭和画面设置按钮的材质及反馈。保留入口位置、文字、事件与业务决策，比例按V2调整，触控目标至少44px。核心 `#fightHold` 使用V7专用几何和回弹，不受通用规则影响。

V1初始规则（V2覆盖其状态强度与尺寸）：默认浅海盐绿哑光软面，主操作为暖杏色；次级折叠/详情入口采用轻背景而非另一枚大主按钮。hover只在 `(hover:hover) and (pointer:fine)` 中小幅提亮/抬高，不改变主题；触控不会留下鼠标悬停色。按下压低侧沿并有2px下沉，选中比默认更清晰但不变成深绿底块；禁用保持可读并取消hover/按压/光泽。焦点使用独立轮廓，不等同选中。

## 接口与优先级

新增 `src/button-states.css` 最后加载，作用于游戏、结果/手记/出行对话框和body画面设置面板的button/交互summary，排除 `#fightHold`。使用统一颜色/侧沿变量，保持既有尺寸与锚点；地图钓点保留水平定位，不允许旧hover改变transform而跳位。缩放组保持一体结构，子按钮没有独立大阴影。

选择读已有 `.selected/.active`、`aria-pressed/aria-selected`，展开读 `aria-expanded` 或所属details的open。镜头按钮与手记分类补齐aria-pressed，设置入口沿用现有aria-expanded及aria-controls并随开关同步；声音/选饵沿用已有语义。属性只反映既有状态，不驱动游戏逻辑。优先级：默认→选中/展开→hover→按下→禁用；减少动态关闭通用位移过渡，保留颜色/焦点可见。

旧全局hover规则改为仅fine-hover可用，解决触屏粘滞；新的最后样式层覆盖遗留选中颜色和按压缩放。装饰伪元素不能接收输入。未知状态落回默认；CSS缺失不改变操作语义。

## V2：状态辨识与控件比例

依据用户截图，V1选中/按下差异过弱、瞄准抛竿横条过宽、图标套框偏小。V2保留温暖柔和材质：hover同时增强边线与面色、抬升2px；选中使用中浅鼠尾草面色、深绿边线及明显内沿，不采用深绿整块底色；按压下沉3px并压暗表面/收短侧沿。三态分别表达接近、持续选择、当前受力，禁用仍最后覆盖，触屏不依赖hover。

新增每种材质的hover色变量，主按钮保持杏色，选中保持绿色，不因hover回到默认配色。缩放组、手记页签、次级选择同样加强背景与内沿反馈，展开详情有明确填色。瞄准工具条右对齐：抛竿弹性宽度clamp(160px,55vw,248px)、高64px，取消80×56px，间距12px；窄屏不小于44px且允许主按钮收缩。抛竿图标30px/文字18px，去除图标独立小底框。镜头角度与视角入口统一48×56px，缩放组外宽48px、子按钮44px；工具触控区域不跟随按压缩小。保留footer安全区、目标水面与鱼竿布局，不修改V7核心控件。横屏仅兼容，不按横屏扩张主按钮。

静态测试验证状态颜色/边沿/位移、材质hover变量、窄屏尺寸范围、镜头组内外尺寸及图标去框。实际视觉不做已验证声明。

## 验证与性能

Node测试覆盖实际样式加载顺序、hover门控、所有按钮组的状态覆盖、核心控件排除、地图锚点、禁用优先级及真实视角/页签/设置开关属性接线；既有操作、回流与V7手势回归，运行npm test/build及差异检查。按用户要求不使用Computer Use、浏览器或游戏内视觉验证，也不生成替代游戏截图。CSS实际布局、真机触感及极端文本长度待验。不新增位图、3D绘制、shader或持续动画；低端设备以后检查快速点按/拖动与设置开关时的帧时间。
