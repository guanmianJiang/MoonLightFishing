# 钓获选择后的动作、声音与提示

## 目标与范围

在 9:16 触控近景中，使放流、记录、收藏和入篓都有可读的短动作。放流重点表现重力加速、真实入水接触和游离，允许适量夸张冲击。沿用暖海岸风格与现有模型、水花，不增加奖励、经济循环或长演出。本规格补充 fishing-loop-spec.md 与 outcome-feedback-spec.md。

## 数据与接口

- `catchProcessFeedback(action,caught,fish,result,at)`：返回只在内存中的事件，包含 action、object、weight、at、duration、title、hint、resultText。提示消费实际结算结果，追踪位满不能宣称已加入追踪；杂物放回不提示游走或活体追踪。记录、收藏、入篓提示各自用途。
- `releaseTrajectory(start,end,weight,object)`：三维数组输入，求解相同重力（11.8 m/s²）的落水时刻和水平初速度。重量只影响冲击大小，不改变重力。无效位置安全回落，起点不低于水面；起始速度轻推而非高抛。
- `sampleRelease(plan,age)`：输出 position、velocity、phase、immersion、visible、impactStrength。空中按解析弹道，每帧不积分、不缓入缓出；水面交点连续且只触发一次接触。入水先消耗向下动量，再转为横向游离；杂物只下沉，不能摆尾。隐藏页恢复跨过接触点时不补播迟到的水声/振动。
- `processCameraCue(event,age,reduced)`：连续有界镜头权重。处理开始捕获实际相机和模型位置；放流跟随下落/水面，记录短停留，收藏及入篓随收纳微退。减少动态效果关闭附加推移，保留物体重力与接触。
- 场景 `beginCatchProcess(event)` 在清空 pending 前接管当前钓获模型，保持尺度、材质和首帧位置。恢复结果时无场景模型则使用已缓存/可用模型与手边起点。短演出结束隐藏模型并回到准备镜头，不重新分配每次放流的模型。
  大鱼处理期间延续站立托举，不能关闭结果窗就立刻坐下，让鱼与手错位；恢复钓获使用实际手部世界坐标，不用人物根节点上方的固定偏移。

## 时序与界面

1. 点按选择后，`processCatch` 立即结算一次并保存，关闭结果窗。容量错误保留原结果窗，不启动演出。
2. 内存事件进入 processing 模式，短暂隐藏准备按钮/路线/选点入口，复用水边小提示。放流最长 1.85 秒，其他操作 1.25 秒；不显示新弹窗。提示说正在执行什么，接触后再说明已放回及追踪状态。
3. 放手声立即播放；水声与短振动由场景越过计算的水面交点时触发。水花大小及音量/音高适度反映重量，不能使小鱼像重物砸水。杂物不播放活鱼旋律。记录使用落笔式轻点与清晰两音；收藏使用温暖收纳声；入篓使用低一些的落定声。
   恢复钓获后首次点选仍从用户触控启动音频。资源尚未解码的 HTML 音频回退，短片段时长应从实际开始播放计，不应在加载完成前被自己的结束计时器暂停；未能在 250 毫秒内开始则丢弃，静音/后台/替换结果优先取消。主动取消引起的 AbortError 不作为播放失败记录。
4. 动作完成才显示一次实际结果提示；发现文字优先，保留完整结算在 observation。提示标题分别为记录已保存、样本已收藏、已放入鱼篓、已放回水里/原处，不能把放回杂物称作“新收获”。线索不再用旧定时器覆盖本次结果。本轮最后一竿的回顾等动作结束后打开。
5. 重复点击、更新、刷新不重复结算/演出；事件不进入存档。页面切后台时结束展示并取消迟到的接触反馈；刷新仍由已有已结算轮次恢复回顾。渲染初始化失败也可完成结算与提示，不永久锁住操作。

## 性能与异常

### 动作衔接修正（第二版）

- 处理开始捕获上一帧经过 IK 约束后的手部、肘部、竿角与身体倾斜，沿原托举姿势进入放流/收纳，不能因 pending 清空一帧切回垂钓握姿。`processGesture(event,age,flightTime,reduced)` 输出有界的 `hold/reach/lower/offHand`；放流前伸在约 100 ms 达峰，入水后 180 ms 内收回，托举在入水后 400 ms 内连续退出。其他动作随收纳进度降低右手，记录只短停留。右手在处理时独立于握竿辅助点，主手仍握住竿。减少动态时关闭额外前伸，保留姿势衔接。
- 头部视线随当前钓获下落/收纳，避免关闭结果窗就先看向下一竿浮漂。过程中隐藏范围圈、落点、临时选择圈和闲置鱼饵，关闭水面选点、环绕及缩放；开始时清理旧指针/水面交互，结束恢复原触控。
- 水花复用既有 48 个网格池；`src/water-impact-motion.mjs` 中的 `splashDroplet(strength,random)` / `sampleSplashDroplet(plan,age)` 生成初速度、尺寸及解析重力位置。水滴重力为 11.8 m/s²，以速度方向拉长，最高点缩短，触水立即回收。小水滴半径 0.010–0.022 m；力度改变抛起速度和数量，不能让大白球在空中缓慢漂浮。按实际经过时间采样，不用渲染帧的限幅 dt 累加；异常强度/随机数安全限幅，负时间停在起点，失活水滴不补生成二次水花。
- 浏览器复核放流、记录和收纳首帧姿势、入水后收势，以及短演出后的下一竿入口。既有咬实取景、搏鱼判定和声音调度保持各自规格。

仅接管当前模型、复用水花池；无新 shader、全屏滤镜或常驻 draw call。保留帧率下降时解析位置与准确的一次入水判断。不能支持振动的设备照常呈现画面/声音。声音继续遵循现有开关、首次触控解锁和后台规则，不改变偏好。真机扬声器与低端移动 GPU 尚需实机检查。

## 验证

Node 测试检查弹道重力/速度、交点连续性、质量差异、不摆尾杂物、无效输入；处理提示事实、镜头边界/减少动态；实际应用处理函数的立即计账、重复操作、延迟回顾、错误保留。浏览器检查真实结果选择路径及 390×844、320×568 画幅，截图记录下落/接触/游离；音频测试检查不同处理事件与静音门控。构建与全套测试通过后更新 IMPLEMENTED。
