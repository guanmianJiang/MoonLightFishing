# 鱼体游动与阶段衔接

## 目标

继续使用现有鱼种、暖色材质和鱼嘴锚点。补上身体后段到尾部的连续侧摆、胸鳍划水和轻微鳃部呼吸，让靠钩、咬实、搏鱼、出水、托举、放流各阶段可读。小鱼频率稍快，大鱼更沉；老金鱼保留缺尾轮廓。允许适度夸张，动作不参与胜负、鱼距或张力计算。

## 数据与接口

- `fishAnimationTarget(caught,cue)`：输入实际 id/weight、stage（approach/hooked/fight/landing/held/release/swim/viewer）、effort、surge、hookAge；输出角频率、相对鱼身长度的摆幅、胸鳍幅度。重量限幅，未知鱼使用普通活鱼配置；瓶子/铃铛/标记 object 输出零动作。虾使用上下收尾，不套鱼的左右游动。
- `createFishAnimation(caught).update(cue,dt,reduced)`：每实例保持相位，平滑频率/摆幅并积分相位；阶段变化不重置相位。无效/负 dt 不前进，大间隔限幅至 0.1 秒，后台恢复不追补挣扎。减少动态保留低幅游动，抑制夸张摆幅。
- `createFishBodyRig(model,{id,headDirection})`：为发生变形的网格克隆几何，缓存静止顶点/法线和局部到资产根坐标矩阵。头前部与 MouthAnchor 不动；身体后部渐强的行波传到尾尖，背鳍、条纹和尾鳍使用同一形变以避免脱离鱼体。胸鳍围绕实际根部划水，鳃部仅微呼吸。模型、材质、三角形数和 draw call 不增加；按变形导数修正身体法线并预留包围球，避免剔除。`dispose` 只释放实例自有几何，幂等。
- `animateSpecimen(model,caught,cue,dt,reduced)`：统一真实场景与图鉴驱动；每帧只在当前活鱼展示阶段调用一次。异步替换继承旧实例驱动器，避免相位跳变；失败使用同样支持身体动画的程序备用鱼。动画实例不进入存档。

## 阶段与边界

靠钩为轻摆和慢划鳍，咬实在约 260ms 内进入强动作；搏鱼摆幅来自真实 struggle/pull、surge，松线只减小受力部分，鱼自身仍会游动。出水短暂扑动随上岸时间衰减，托举时低幅呼吸和偶尔尾动，不能一直激烈打手。放流空中低幅收尾，入水阻尼期轻摆，恢复主动游离后再加快。杂物全程不生成活体动画。保留当前世界位置、朝向、重力与水面接触时刻。

## 鱼身圆润度

`tools/generate_specimens.py` 保留六鱼种原有长度、高宽、头尾端与配色，按原六环半径曲线以限幅 Catmull–Rom 重采样为 32 环×24 截面，并使用平滑法线。小银鱼侧纹沿同一半径曲线贴体生成；鱼鳍轮廓和老金鱼缺尾保留。GLB、缩略图、源 blend 与 manifest 同源重新导出，嘴锚位置不改。每物种三角形仍小于 6000；这是现有模型细化，不增加贴图或鱼种。复核近景轮廓、腹背材质分界、侧纹接缝及 CPU 变形后的顶点预算。

## 性能、验证与异常

仅当前可见钓获/图鉴更新 CPU 顶点，不新增 shader、纹理或渲染通道。重复加载不修改缓存原件；旧钓获退场和世界销毁释放实例几何。测试覆盖阶段/重量/虾与杂物/非法输入、相位和摆幅连续性、真实七种 GLB、嘴锚误差、尾根与法线/包围范围、缓存保护和释放。浏览器在 390×844 和 320×568 检查真实资产、阶段连续帧以及实玩上岸/放流；横屏仅兼容。低端手机需持续搏鱼 60 秒记录帧时间、draw call 和连续 20 竿几何内存；桌面预览不能代替该验证。
