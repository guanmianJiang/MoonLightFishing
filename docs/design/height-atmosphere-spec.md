# 天际线高度雾与大气散射

版本：`2026.10-atmosphere-reflection-review`，继承 `2026.10-height-atmosphere`。替代 `2026.10-atmosphere-controls` 的距离雾模型；遵循 `HANDOFF.md` 的清亮暖海岸基调。

## 目标与范围

表达海面附近较厚、随世界高度变薄的空气层。天空、天空倒影、远水、岸边物体共用高度密度和散射颜色，雾集中在天际线附近；俯看浅水和抬头看天空保留颜色。移除 Three.js `FogExp2` 和水面按距离平方增长的独立雾，不通过降低旧距离雾倍率冒充高度雾。

这是平面海岸空气层的解析单次散射近似，不是完整行星大气或体积云。距离是穿过空气层的路径长度，不能单独决定雾量：相同路径长度、不同起止高度必须不同；高空水平视线显著比海平面水平视线清晰。

“地平线大气”组默认展开。“关闭散射”只将散射强度置零，不改雾层高度、云层或其他调色。字段有限数/范围校验、即时 uniform、自动保存、恢复、导出和发布默认沿用既有流程。旧 `skyFogStrength`、`sceneFogStrength`、`waterFogDensity` 不再渲染或显示；旧记录三种雾全部为 0 且没有新强度字段时保留关闭意图，其余采用新默认。水、光照、天空选择/旋转等保存值保留。

## 密度与传输

- 海面基准世界 y=0.14 米。密度 `ρ(y)=exp(-max(y-0.14,0)/H)`；H 是降至约 37% 密度的高度。
- 对有限线段按真实世界起止高度解析积分。令 a、b 为起止高度的归一化非负海拔，密度平均为 `exp(-min(a,b)) * (1-exp(-abs(b-a)))/abs(b-a)`。近水平差值用二阶展开，避免 0/0；起止互换结果相同。
- 跨越海面基准的路径按下方恒定密度段和上方指数密度段加权，不能只钳制端点再对整段套用上方公式；水下接收面仍通过捕获标记跳过空气传输。
- 光学厚度 `τ=0.0006 * L * meanDensity * strength * weatherScale`；散射权重 `1-exp(-τ)`，最多 0.985。L 限制在 0–12000 米。零强度真正输出 0；晴天/雨后/雾天的天气倍率为 1 / 0.9 / 1.45，未知值回退 1，不再单独打开深度雾。
- 天空和其倒影按 12000 米空气路径、起点世界高度及方向仰角采样空气。下半球环境代理取绝对仰角，避免假天空在地下积累全覆盖雾。天空几何球半径不决定空气散射距离。天空球起点是相机，倒影起点是水面。
- 天空方向由球面世界位置减相机位置计算，避免相机升高后把球心方向误当视线方向、改变天空散射的仰角。
- 相机远裁剪从 2400 米扩到 16000 米，纳入已有约 12 公里海面；网格与细节密度不变。不能依赖旧的距离雾覆盖裁剪造成的海面终点。
- 颜色在线性空间按 `source*T + inscatter*(1-T)` 合成，之后执行既有曝光/色调映射/输出色域。散射用克制的蓝青 Rayleigh 色和有界的向阳暖色 Mie 近似；相位随真实太阳方向、颜色变化，天空与水面使用同一函数。没有额外固定去饱和层或纯白填色。

## 引擎接口

`src/height-atmosphere.mjs` 提供共享 GLSL、天气倍率、解析标量函数，以及 `createHeightAtmosphere(settings,lighting,camera)` 返回 `{uniforms,install,setWeather,beginCapture,endCapture,dispose}`。

- 天空/主水面/水膜共享 uniform 对象和 GLSL。水面眼到表面的空气路径独立于波纹法线；其反射环境先按水面高度计算天空空气，再计算观察者到水面的空气传输。
- 普通材质在既有 `onBeforeCompile` 后替换标准雾块，世界坐标由动画/实例变换后的 `mvPosition` 和相机世界矩阵恢复；混合发生在 tone mapping 之前。保留原材质修改和程序缓存键；不修改全局 ShaderChunk。渲染前发现可见的新异步材质，安装一次，均匀值修改不重建 shader。
- 折射捕获阶段，低于海面基准的沙底/鱼不预加空气雾，避免主水面再计算眼到水面时重复遮盖；捕获标记用 try/finally 恢复。水体吸收/散射继续属于水下路径。
- 场景不创建 Three.js 普通雾；天气仅更新共享倍率。销毁时恢复本系统安装的材质钩子。

## 边界与验证

近水平、相同高度、负高度、负距离、极远路径、零强度、极薄/极厚雾层均输出有限值；相同距离不同海拔可区分。天空抬高仰角后散射下降，高空水平视线也下降；调整高度不改变云贴图的位置或相机。

Node 测试直接执行 GLSL 标量函数，对照数值积分；测试材质钩子保留/缓存/异步新材质/重复安装/销毁、折射捕获去重、旧参数迁移与发布边界。视觉验证以 390×844 为主，覆盖默认/关闭/薄厚层、低高仰角、近景/等待/收线/俯瞰、六天空与天气，以及 320×568 和横屏兼容。检查连续海天过渡和高处不被雾染色。

不增加贴图、draw call、render target 或天空纹理采样。每片元增加少量指数/相位运算、普通材质增加世界坐标 varying；每帧一次可见材质发现遍历。低端移动设备需默认/关闭各运行垂钓与环绕 60 秒，记录帧时间及切换模型时卡顿；桌面模拟不登记为真机验收。

旧 `create-atmosphere-preview`、`create-fog-preview`、`create-sky-preview` 工具作为兼容入口转发至当前高度散射预览，保留各自原 HTML 入口名。旧源码归档至 `assets_pipeline/sky/legacy-preview-tools/`，只用于理解历史报告，不能用当前运行时代码重放旧距离雾对照。

## 散射颜色复核（2026.10-atmosphere-reflection-review）

此前硬编码的线性 RGB `(0.1812,0.4621,0.6172)` 使所有高雾量天际线收敛到同一偏青颜色；太阳归一化后又丢失天气光强。该色彩近似不应宣称为完整光谱大气散射。

- 新增 `atmosphereColor`（“散射基色”，六位 sRGB HEX），回退 `#9fb9d3`，以线性 RGB 参与渲染。旧记录缺少该键时使用回退，非法颜色忽略；颜色沿用画面设置自动保存、恢复、导出与发布校验。
- 雾量仍使用真实高度积分。基色代表美术可调的漫射空气底色，不是水体颜色；天际线采用 `L = source*T + S*(1-T)`，不能通过 RGB 固定去饱和覆盖天空。
- 源颜色 `S = baseLinear*(0.85+0.15*RayleighPhase) + sunRadiance*0.12*forwardMiePhase*sunStrength`。向阳项为受控加法而非替换基色；保留真实太阳光强/颜色，使天气、太阳方向变化一致。0.12 是本项目美术曝光系数，Mie 峰值归一化为 1；不宣称全空间物理归一化或多重散射。
- 基色默认采用较低饱和的蓝灰，太阳侧可偏暖；远离太阳保持冷色。不能默认使用纯白，也不再锁死成水体青色。相位/基色调整均不会改变雾层高度或云位置。
- 复核时发布强度 1.35 在 2 米高度、12 公里水平路径的未钳制雾量约 99.987%，实际钳制为 98.5%，几乎抹掉天空差异。发布基准修正为 0.15（高度仍 22 米、向阳 0.15），同路径约 62.9%；旧浏览器保存值仍尊重用户选择，可在面板恢复默认。其他发布参数保持原值。
- 本轮按用户要求不操作电脑界面。通过实际 GLSL 标量、线性颜色转换、保存/发布边界和构建验证；新的色彩、参数与 shader 不登记为已完成视觉验收，低端真机仍待验。

参考算法：[Bruneton 的分离 Rayleigh/Mie 散射](https://ebruneton.github.io/precomputed_atmospheric_scattering/atmosphere/functions.glsl.html)、[PBRT 相位函数](https://pbr-book.org/4ed/Volume_Scattering/Phase_Functions)。本项目仅采用高度层解析传输及受控源颜色近似，不使用它们的完整行星模型。
