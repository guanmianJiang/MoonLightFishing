# 界面、构建与资源交付规格

> 状态：源码与资源已恢复，构建通过；浏览器交互仍待验收。依据 `package.json`、`vite.config.js`、`tools/verify-build.mjs` 和界面测试维护。

## 目标与范围

界面提供钓点/鱼饵选择、抛竿控制、读漂与搏鱼引导、收获处理、手记/出行摘要及设备本地进度提示。构建把前端代码和运行资源一起输出到 `build/`，供静态托管。

## 数据、接口与依赖

- `package.json` 声明 Vite 6、SolidJS、Three.js；脚本为 `npm run dev`、`npm run build`、`npm run preview`。
- 开发服务的活动入口、样式和画面设置、镜头等本地 ES 模块直接按相对路径导入，不复用手写的固定 `?v=` 查询参数。源码更新后由 Vite 失效模块缓存；发布构建仍由打包文件名区分版本。若浏览器保留旧模块，不应导致新入口请求旧导出而使整个游戏停在启动错误页。
- 竖屏画面设置打开时保留可见的三维画面区域，便于用户观察曝光、水色等参数的即时变化；设置内容在面板内部滚动，保存和恢复操作始终可及。
- 天空球选择与水平旋转沿用画面设置的即时预览、本地自动保存、恢复默认和发布默认流程；资源加载失败时显示错误并恢复下拉选项，不保存失败的选择。天空资源及取值边界见 `docs/design/scene-water-spec.md`。
- 天空保留云层高度倍率；“地平线大气”默认展开，控制雾层高度、大气散射强度、向阳暖散射与散射基色，提供“关闭散射”。旧三层距离雾控件已移除；字段迁移与共享高度雾见 `docs/design/height-atmosphere-spec.md`。环境反射保留基础反射增量、有效角度幂次和法线扰动，不提供倒影模糊/柔度；字段共享保存/发布边界。
- `vite.config.js` 以 `src/` 为源码根目录，输出到 `build/`，由 Vite 复制 `public/assets/`；还引用 `src/render-settings.js`。开发服务器的本地画面参数写入接口需同源、JSON、大小和字段校验。
- `tools/verify-build.mjs` 检查生成页面、JS/CSS 包、关键模型、贴图、字体与音频清单。`npm run build` 已通过。
- 活动界面入口为 `src/app-final.js` 与 `src/ui/`，存档键为 `moonwater-v1`，由 `src/config/game-rules.mjs` 统一定义。

## 输入输出与边界

### 场景工具入口持续可用（2026.10-sky-tools-visibility）

修复等待时设置/手记/缩放被CSS隐藏，以及咬钩、搏鱼、收线时整组工具被隐藏。设置、声音与手记按钮在各阶段持续显示，至少44px，保留原点击逻辑和可聚焦状态；准备操作区依然只在准备/瞄准显示。等待、咬钩恢复现有缩放组；搏鱼镜头复位/缩放、瞄准和结果的原镜头规则保持。工具靠右，350px以下搏鱼时移至状态卡下方，避免压住右上卡片，不依赖hover。

画面设置的天空组明确说明云位置随全景朝向变化，无云方向可以调整水平旋转；不把正常无云天空误报为加载丢失，不自动覆盖玩家天空选择、旋转或雾参数。检查资源像素及方向映射并记录诊断边界；本轮不操作电脑界面，触控/窄屏布局和实际天空仍待验。

### 反射与大气调节（2026.10-render-look-controls）

“地平线大气”和“环境反射”相邻排列并默认展开，位于天空之后。每个参数的作用直接显示在控件旁，用滑杆或数值框触控调整，即时预览和本地自动保存；继续共享既有导出与发布校验。散射基色使用原生颜色选择器。散射强度和向阳暖散射步长细化为 0.01；范围、着色算法及当前发布默认不变。各数值控件、颜色选择器、动作按钮至少 44px 高，内容仍在面板内部滚动，不依赖 hover。

环境反射提供强度、菲涅尔幂次、基础反射增量、法线影响和岸边物体倒影；说明角度过渡、基础反射和波纹扭曲的区别。地平线大气提供雾层高度、散射强度、向阳暖散射和散射基色；说明层厚、雾量与颜色的区别。不增加倒影模糊控件。

两组分别提供“恢复本组”和关闭按钮。关闭仅将该组强度置 0；恢复读取当前发布默认对象（包括本次会话刚发布的参数），只恢复所属字段，大气组包含基色，不改天空选择/云高、水体吸收、光照或另一组。恢复后同步滑杆、数值及颜色并自动保存；存储失败显示可下载配置的提示。

`src/render-look-controls.mjs` 提供静态说明、`restoreLookGroup(target,defaults,title)` 和 `clearReflection(target)`，不依赖 Three.js/DOM。恢复对有限数钳制，缺失或非法值采用字段回退；颜色只接受六位 HEX，未知组返回 false 且不修改对象，合法组返回 true。关闭返回目标对象且不影响其他字段。

Node 测试覆盖两组独立恢复、最新发布值、缺失/非法/越界输入、关闭后 JSON 保存与 uniform 响应。构建验证模块接线；本轮遵循用户“别调用电脑”要求，不操作界面，竖屏布局/颜色选择器实机表现待验。无新增 draw call、纹理或 shader 运算；低端手机后续应在 320/390px 竖屏滑动两组并调整极值，观察连续预览和内部滚动，默认/关闭各运行 60 秒记录帧时间。

用户输入可来自触摸、鼠标和键盘；界面应把操作映射到同一游戏状态。移动端拖拽必须落在可及水域，桌面画幅居中。存储失败应明确提醒。关闭收获弹窗不得无意替玩家作出记录或放生决定。

空钩反馈使用水边现有观察文字，不打开模态结果窗；钓获结果仍等待玩家明确处理。处理后保持近景和固定抛竿入口，触控可直接开始下一竿。刷新时若只剩无钓获的结果状态，自动结算后恢复此入口。

钓获结果页突出一个建议操作和一个“其他选择”按钮；其余处理方式以触控可及的折叠区呈现。首次记录、特殊/变异/追踪个体也默认折叠，身份标签保留；鱼种/搏鱼明细另由原生 details 展开。展开区用 `aria-expanded` 表示状态，隐藏操作不得进入触控或无障碍焦点顺序。

有可追鱼讯时，准备态状态文字和空钩后的水边观察文字应明确说明同钓点、同鱼饵再次抛竿的机会。鱼讯提示只是线索，不显示命中概率或保证鱼种；更换鱼饵/钓点后准备态不再显示沿原线追踪提示。

准备态路线摘要展示下一片水域、探索进度和剩余竿数，详情内保留获得方式及可执行的路线动作；新水域开放后从详情直接选点。近景钓点标记简化为名称，俯瞰标记可包含入门/进阶/挑战，瞄准态说明当前近水或远水落点的实际差异。短屏收起次要说明和装饰，保留进度、主按钮及 44px 手记入口；探索逻辑见 `docs/design/progression-guidance-spec.md`，界面净空见 `docs/design/coastal-ui-spec.md`。

## 异常与验证

2026-10-01钓获页继续以纯UI层次呈现收获：标题与身份并排、真实鱼体放大、评级置于鱼名旁、关键属性与选择分区；增加小于400ms的一次入场和暖杏主按钮的下沉复位反馈，不使用新增装饰图片或循环扫光。恢复结果不重播揭晓，320小屏展开选择仍保留鱼名、评级和属性；规格见 `coastal-ui-spec.md` 的“钓获揭晓与主动作反馈”，实画与未验项见 `docs/validation/ui-catch-reveal-2026-10-01/report.md`。

缺少 `src/`、关键资源或工具依赖时，构建应失败并报告具体缺口，不得把旧构建副本当作发布目录。`tests/result-dialog.test.mjs` 读取活动入口，`tests/trip-summary.test.mjs`、`tests/cast-target.test.mjs`、`tests/project-structure.test.mjs` 和 `tools/verify-build.mjs` 提供自动验证；交互可用性仍需浏览器与真机检查。

本地页面在游戏脚本尚未初始化时显示可读的加载状态，不得把原始 HUD 与空背景当作可玩画面。游戏完成首次场景与界面初始化后清除加载状态；模块加载失败、初始化异常或超时要显示错误与重试入口。诊断只覆盖启动阶段，不把运行中普通资源警告误报为启动失败。
