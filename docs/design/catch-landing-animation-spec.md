# 上鱼后的提拉、悬挂与挣动

## 目标

9:16触控游戏中让真正上鱼后的活体和重量可读。保持3.2秒结果展示时长和既有胜负、鱼嘴锚、线端与暖色资产。正常搏鱼成功继续用既有举竿停留姿势，不重播卷线；叠加一次有重量的提拉和卸力。杂物不套活鱼挣动。

## 数据与接口

- `landingCatchReaction(airAge,weight,reduced)`：基于完全离水后的事件年龄生成三次逐渐减弱的短收缩，输出 `burst/curl/roll/yaw/sway`。小鱼更快、大鱼稍慢；坏年龄/负年龄静止、重量限幅，减少动态降低幅度。纯时间采样，不依赖渲染帧率，不用全局时钟随机抖动。
- `landingFishPose` 保留旧接口，增加可选 `{airAge,reduced}`，在悬挂朝向上叠加上述有界摆动；嘴向上、尾向下，保持单位方向。收缩不能使鱼嘴脱离鱼钩。
- `fishAnimationTarget` / `createFishAnimation` 增加可选 `airAge` 与输出 `curl`：真实出水阶段以事件脉冲驱动摆幅和收腹，摆尾相位连续；普通held/viewer保持安静动作，未离水不提前播放空中甩动。状态不保存进存档。
- `fishBodyWave` 增加有界curl中心线偏移（最多鱼长的0.18）和解析导数；收腹以24/s快速收敛，普通游动保持9/s，避免短拍被平滑抹掉。所有鱼体/鳍/条纹共享，头前部、嘴锚不变。包围球按鱼长0.33增加预留，不增加网格或shader。
- 场景每竿记录 `revealAirAt`，当实际鱼体世界包围盒最低点超过水面0.025m才启动。模型异步替换保持事件年龄。新竿清空，晚恢复到已经收稳时不补播。实际搏鱼成功也消费 `landingDynamics` 的一次提拉，失手与杂物跳过。
- `handoffSpecimen(previous,next)` 为迟到模型保留尺度/姿态/可见性、鱼嘴世界锚和动画驱动器；当前搏鱼或出水引用一起交接，随后释放旧实例变形几何。旧竿/已处理钓获的迟到加载不能替换当前模型，失败继续用备用鱼。备用鱼不能因已经进入搏鱼而永久挡住正式GLB。

## 节奏与边界

离水后约0.06–0.34秒第一次收腹甩尾，约0.52–0.82秒较轻第二次，约1.02–1.28秒最后一次；重量缩放时间最多20%。每次有收缩与松回，空隙安静，约1.55秒后仅呼吸与小尾动。悬挂朝向、身体弯曲和反向松回同源；不让活鱼一直像在水里匀速游动。虾沿原竖向收尾，瓶子/铃铛全程零活体动作；减少动态保留基本提拉和钩点约束。

## 验证与性能

纯逻辑覆盖脉冲峰/间隙/衰减、重量、30/60/120Hz时间采样、异常值、相位/阶段连续和嘴锚。实际GLB检查curl法线与包围范围；实际场景验证正常搏鱼成功提拉启用、新竿重置和事件离水门槛。390×844、320×568核对出水到展示连续帧，横屏兼容；实际触控上鱼到处理回归。沿用当前可见鱼体CPU变形及水花池，无新材质/纹理/渲染通道。低端安卓连续20竿记录帧时间和几何内存；桌面不能确认手机手感和实际扬声器。
