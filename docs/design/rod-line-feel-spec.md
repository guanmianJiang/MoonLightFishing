# 钓竿、鱼线与触感第二版

## 目标与范围

沿用现有触控收线/抬竿/下压、搏鱼胜负和暖海岸画面。解决直接位移弯竿导致的竿长变化、帧率依赖的张紧和随机相位线抖，让“接力—蓄力—让力—回弹”由实际负载驱动。保持已有按当前蓄能释放的断线/脱钩响应，允许风格化强回弹。没有新的数值升级、胜负门槛或操作要求。

## 数据与接口

- `src/rod-elasticity.mjs`：`stepRodSpring(position,velocity,target,dt,frequency,damping)` 为解析欠阻尼受迫弹簧响应，返回位移/速度，正常取载与卸载快速但连续；异常值安全回落，dt限幅0.1秒。`rodStoredEnergy(bend,velocity)` 输出0–1强度，给终结触觉使用。
- `writeRodCurve(points,start,axis,pull,bend,lag,length)`：复用28个点，通过单位切线积分形成柔顺曲线，竿柄段刚性、上段渐软，负bend自然反弯；所有段长之和等于3.55m，竿根不漂移。力方向去除轴向分量，退化共线时使用稳定下垂方向；弯曲角与滞后有界，不能被大数拉成无限长。输入输出都是局部内存数据，不改存档。
- `FishingLine.update` 保留既有接口及38段Verlet/90Hz求解。张紧与收回引导使用按时间的指数权重；外力脉冲使用最多4个有寿命的局部波包，从鱼端传向竿端，抬竿可指定反向。重复力值不重启波，松线不传强冲击。波偏移仅叠加在求解后的画线节点，下一帧先撤销，不累计变成蛇形折线。
- `createHaptics.emit(name,{strength})` 保留原事件名接口，strength可选0–1，以有界短时长表达力度，不能假定手机支持振幅控制。终结事件仅由stopFight发一次，断线/脱钩强度读取最后实际竿弯与速度；绷线接力触觉来自从松到紧的状态跨越，低优先级卷线振动不能盖过终结。
- 场景暴露只读 `getRodFeedback()` 返回当前蓄能强度；角色、竿根和线锚仍共用经过IK的手。搏鱼镜头仅增加同一弹簧速度驱动的克制退让（小于0.07m），减少动态关闭附加位移。

## 阶段与边界

正常收线在约0.2秒内建立弯曲，竿尖比竿柄多弯；松手/让线随真实负载变化回直，而不是按按钮立即甩。咬实、抬竿的首拍清晰，抬竿波从竿端向鱼端传递；鱼冲刺传向手端。断线和脱钩继续捕获真实bend/velocity与前一帧力方向，首帧竿线位置连续；断线短线不再连着鱼。空线与杂物使用安静负重，不给活鱼挣扎。新竿、刷新、后台恢复不重播旧脉冲。

重载和失手镜头按实际竿身点投影安全边缘，必要时仅沿视线后退以保留弯曲/反弯轮廓。`frameRodCamera(shot,points,aspect,fov,zoom)` 保持焦点与方向，扩展距离；坏输入不移动。失手后仰改为有界目标角度的按时间收敛，不能把每帧卸力kick加到人物角度，30/60/120Hz保持一致。

## 性能与验证

复用28点竿身和38点双描边鱼线，无新shader、网格、材质、draw call或常驻滤镜。解析弹簧和波包工作量有界。测试正常受载、卸力/断线回弹、段长、力向/根锚、30/60/120Hz一致性、波传播/去重/松线/非法输入、终结触觉与后台停止；实际场景接线回归。390×844与320×568检查抛投、绷线、收线/让线、重载断线、回弹后的自由端；横屏仅兼容。低端安卓需连续搏鱼60秒记录帧时间，真机检查触控延迟、扬声器和振动同步；桌面不能确认设备振幅和系统振动精度。
