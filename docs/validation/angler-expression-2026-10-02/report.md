# 角色表情验证（2026-10-02）

## 规格与代码

先建立 `docs/design/angler-expression-spec.md`，并在结果音画规格中关联。纯判定读取现有鱼讯、张力、结果及处理事件；眼、眉和嘴的动画独立于身体 IK 和原头部观察方向。

等待为轻微笑意与约 4.8 秒一次短眨眼；咬实前 280 ms 有小惊讶，随后专注；搏鱼按有效张力/负载收眉眯眼，松线舒缓；活鱼上岸逐渐笑开，杂物单眉好奇。断线/脱钩短惊讶后转遗憾，2.2 秒内回到平静，新的抛竿不会继承旧失败。记录专注，放流温柔，收纳满足。

绑定实际 GLB 的独立眼眉嘴部件。两眉绕自身中心轻转；一个口型网格复用 147 顶点缓冲，开闭时保持圆润；眨眼以共同中心关闭眼白/高光与瞳孔。加载完成使用最新表情，独立几何不修改缓存资产，销毁释放一次。

## 一致性、性能与未验项

实际状态→表情目标→过渡→模型绑定接线一致，提示/奖励/音频/振动未增加。沿用原角色形体和材质，本轮不属于资产重制。不增网格、材质、纹理、shader 或常驻 draw call；口型稳定后不上传缓冲，复用包围球及几何，仅增加小量面部计算。

测试工具只在独立来源初始化存档；临时 HTML、标签页及服务已清理，画幅恢复。工具和实现路径使用仓库相对路径。

仍需真实手机确认微表情辨识与主观节奏；背侧机位不保证每个阶段都能看到眼和嘴。低端机保持原画质，连续 60 秒比较帧时间/draw call，20 竿后检查内存、后台/前台以及减少动态设置。桌面截图和 CPU 单测不代表移动 GPU 验收。
