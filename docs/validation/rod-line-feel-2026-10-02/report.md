# 钓竿与鱼线手感第二版验证

## 修改与规格

规格：`docs/design/rod-line-feel-spec.md`；主搏鱼规格已建立交叉引用。保持既有搏鱼判定和触控输入方式，改动竿身弹性、鱼线传力、少量镜头取景和振动节奏。

- 固定3.55m中心线长度，竿柄保持刚性，竿尖渐软。解析弹簧保持受载/卸力速度连续，30/60/120Hz取载相同。
- 断线和脱钩捕获最后真实弯曲、速度和力向，保留已有按蓄能放大的反弯；断线自由端不再连鱼。
- 鱼线局部波包按来源传递，抬竿与鱼冲刺方向不同；松线不传强冲击，恒定负载不反复起波。时间权重代替按帧的张紧权重。
- 振动以短时长变化表达实际传力强度，加入重新绷紧接力事件；终结仅发一次、优先于卷线。浏览器振动接口没有可移植的振幅控制。
- 视觉检查发现竿尖出画和失手后仰逐帧累积，已修复：按竿身投影后退取景，后仰改成有界目标角度按时间收敛。

## 自动检查

- 新增14项：竿弹性8项、鱼线3项、振动3项。关联的真实触控绑定回归一并通过；重点覆盖固定长度、根锚、反向受力、首帧连续、退化输入、波传播/消退/重置、松线接力、力度缩放、终结唯一性、镜头投影和后仰帧率一致性。
- 实际场景竿身与后仰语句在VM里运行；终结测试执行实际 `tickFight` / `stopFight`，检验失手当帧读取蓄能、只触发一次并清理搏鱼。
- `npm test`：当前共享工作区700项通过，0失败；该总数包含工作区其他并行改动。
- `npm run build`：122模块构建通过，页面、模型、贴图和音频资源校验通过。主包gzip155.03kB为共享工程当前结果，不登记为本功能单独成本。

## 性能与一致性

没有新增网格、材质、shader、纹理或渲染通道。沿用28点竿身和38点双描边鱼线；波包最多4个，固定寿命；取景计算复用临时向量。场景 `getStats()` 返回的是最后一次渲染统计，不能据此把页面显示的draw=1当成全帧draw call。

源码、单测和规格在固定长度、受力方向、事件去重、时间权重及失手取景方面一致。镜头投影与解析弹簧有自动检查，风格化轮廓已人工看图；实际声卡输出和手机触感没有在桌面确认。

## 待真机确认

在支持振动的安卓浏览器连续搏鱼60秒，记录中位/p95帧时间、内存和GC停顿；检查松线/抬竿/断线触控到画面、声音和振动的时差，以及后台切回不重播。iOS和不支持振动的浏览器继续保留音画反馈。低端GPU、系统振动精度、扬声器实际可听性和玩家对夸张幅度的主观评价尚未验证。
