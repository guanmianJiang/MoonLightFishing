# 浅海盐绿、动态图文与左上提示验证

日期：2026-10-01。版本：`2026.10-soft-status`。依据玩家四张实画反馈继续修改已有 UI；上一份 `ui-refinement-2026-10-01/report.md` 中的深绿材质和居中通知定位被本轮替代，历史截图保留。

## 对应修改

1. 深绿大面积底板提亮为低饱和浅鼠尾草绿/海盐绿，文字改深绿。主按钮保留暖杏色。路线/操作台圆角28px、线轮与钓获32px；高光和阴影改为柔和过渡，去掉厚重锐利的深色底边。
2. 选点说明从底部操作台移到 `#game` 的左上，x=14、y=78；底部独立取消/抛竿及其触控行为保留。通知存续时同位置的选点/读漂/上岸说明临时隐去，通知移除后恢复。
3. 定位到动态图文消失的原因：已有 `#fightBeat`、`#fightRig` 继续计算实时状态，但在多层后续样式里被 `display:none` 隐藏。本轮将二者移入 `.fight-heading`，恢复鱼图标与鱼、竿、线示意；鱼距、松线、负载和游向仍使用真实物理数据。主状态、距岸及风险保留，移除重复图示文字底框。示意不接收指针，未改线轮112px手势区。
4. 准备态通知改为游戏左上，处理结果不再同时写入中央 story；普通处理、追踪、事件分别只有一条提示。水边观察数据保留。320×568隐藏重复鱼饵说明，选择名称与勾选仍在按钮内。
