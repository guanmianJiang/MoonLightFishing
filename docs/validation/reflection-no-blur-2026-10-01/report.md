# 撤销额外倒影模糊

版本：`2026.10-reflection-no-blur`，日期：2026-10-01。

额外加入的倒影柔化超出用户要求，已撤销。删除 `reflectionRoughness`、面板“倒影柔度”、发布默认 0.25 和按粗糙度抬高 LOD 的函数；旧保存字段不再进入渲染或 uniform，发布合同不接受该额外键。

主水面和保留的岸边水膜按真实反射方向采样天空纹理。经度导数回卷后交给普通纹理像素过滤，处理远处像素采样和经度接缝；没有人为模糊半径、粗糙度最低层或额外模糊 pass。普通纹理过滤不保证所有视角强制读取最高分辨率 texel，它只依据实际像素覆盖，避免闪烁和错误接缝。

保留此前的大气颜色/高度、Fresnel 控制修正、太阳高光去重和水体/倒影调色分离；其他画面参数未修改。

验证：

- `related-tests.log`：相关 29 项通过，覆盖移除后的采样、经度导数、旧字段忽略、无 uniform、反射方向/光学与设置合同。
- `full-tests.log`：全量 473 项通过，0 失败；同一工作区还有并行修改，以当前日志为准。
- `build.log`：构建和资源校验通过。
- 活动 shader 不再包含 `reflectionRoughness` 或 `waterReflectionLod`；源码仅保留一处删除旧字段的兼容处理。规范、面板、发布默认与测试一致，已跟踪文件差异空白检查通过。

不新增绘制、贴图或捕获目标。继续遵守用户不操作电脑界面的要求，没有浏览器验证；当前 GPU 实际编译、画面和低端真机性能待验。先前复核报告中的柔度参数、LOD 数据与构建记录属于撤销前版本，不能代表当前实现。
