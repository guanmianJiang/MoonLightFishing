# 画幅对齐、钓获减负与悬浮操作台验证

日期：2026-10-01。完成版本：`2026.10-ui-refinement`。

## 目标与实际行为

- 宽窗口内通知以 `#game` 的实际宽度定位；模态错误提示挂到当前原生 dialog，避免落在遮罩之后。通知不拦截触控，仍按原有 1.8/4 秒消失。
- 钓获页用海绿底、暖金主按钮与淡金文字；鱼名、重量/长度/评级优先，说明与搏鱼记录收进独立详情。所有钓获默认只呈现一个根据真实目标、容量和对象类型计算的建议；其余三个处理入口需点“其他选择”。首次、特殊、变异、追踪身份保留，不自动处理玩家钓获。
- 放流、鱼篓、收藏、记录及属性使用统一线条 SVG 图标；按钮仍保留名称与真实后果，不能只靠图标猜测。
- 瞄准的大块浅色底板撤掉：一句短提示独立悬浮，取消与抛竿各自成按钮。准备态拆成路线与选饵操作台；顶部/镜头/搏鱼控件统一海绿，主动作暖金。手记保留柔和阅读纸色，重复列表底框改为分隔行。
- 不更改抛竿扣数、抽鱼、奖励、容量、提竿与连续收放线逻辑。原有 112px 搏鱼输入区保留。

## 自动验证

- 新增 11 项 UI 回归：`tests/catch-choice-markup.test.mjs` 6 项、`tests/toast-frame.test.mjs` 4 项、`tests/catch-result-ui.test.mjs` 新增 1 项。覆盖四种处理、真实后果、转义、未知图标回退、目标数据边界/无副作用、特殊与追踪默认折叠、通知宿主与时效。
- 调整现有结果测试，核对建议按钮焦点、首次钓获折叠、显式处理及展开状态；notable 测试标题同步为身份标识，不再描述自动展开。
- 最终完整 `npm test`：379 项通过，0 失败。数字含当前工作区其他模块测试，不把这些测试计作本次 UI 新增。
- `npm run build` 和构建资产校验通过：90 模块，CSS gzip 38.32 kB。新图标为内联 SVG，无新增位图下载；路线装饰沿用已有 `public/assets/ui/shore-journal.webp`。
- 本次 UI 改动不新增 Three.js draw call、shader 或模型贴图。复杂渲染与低端设备性能不能由 CSS 构建证明。
