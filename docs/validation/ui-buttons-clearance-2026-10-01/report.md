# 按钮层次与搏鱼竿线净空验证

日期：2026-10-01。版本：`2026.10-buttons-clearance`。依据玩家最新两张截图继续修改现有界面。规格见 `docs/design/coastal-ui-spec.md` 的同名条款；本轮布局替代上一版宽状态卡，历史报告及截图保留。

## 实现与边界

- 主操作采用暖杏渐变、浅色图标嵌面、柔和高光与接触阴影；按压收紧阴影并下移2px。工具为紧凑软方钮，缩放组合成轻分隔托盘，选饵与主按钮分开。选中、禁用和焦点状态保留，不依赖hover。
- 搏鱼顶部透明容器右对齐，与左侧湾名组成同一顶栏。只给摘要保留小底板，鱼、竿、线动态图在其下透明显示。390宽摘要从原约340×176缩至218×88.5，底板面积减少约68%，顶部从74移到12，让出原第二排。
- 初版只缩窄左上卡片，在480宽实画仍发现覆盖竿尖，随后按规格修正为右上同顶栏。最终截图已经替换为该布局，不能将初稿当作最终效果。
- 沿用原动态图几何和112×112收线按钮，不改变手势捕获、收放线判定、物理、胜负或存档。所有装饰及顶部状态继续不接收指针。无新增位图、Three.js对象、draw call、shader或独立更新循环。
