# 材质V2一致性检查

规格：`docs/design/ui-material-spec.md`的V2部分。

## 当前变化

- 信息浮层、操作承托、工具和阅读区域使用四组不同token，替代一套浅绿渐变复用；暖杏主按钮侧沿从4px增强为5px，按压仍回到短侧沿及3px下沉。
- 未选中鱼饵背景/阴影取消，保留文字与图标；`:where`限制默认选择器优先级，使hover/pressed与选中规则可以覆盖。选中项仍读取真实class/aria属性，未改业务语义。
- 结算图标与箭头取消独立背景/阴影，选择说明去卡片底框/尖角，原说明和动作引导保留。阅读内部卡片减轻背景和侧沿，区分主操作与次级内容。
- 未改变控件尺寸、安全区、布局及核心四向输入，新增模糊区域和持续动画均为0，没有新增图片或3D渲染成本。

- 材质模块7项通过，其中新增2项角色分材质/未选中去框测试。
- 材质、状态、实际画幅与连续受力显示共29项通过；全量713项通过、构建及资源校验通过。共享工作区其他任务也在修改，全量增加数量非全部本轮新增。
- 规格、加载顺序、材质状态规则和IMPLEMENTED条目对应。

按用户此前要求没有进入游戏、没有使用Computer Use/浏览器。测试是源码约束与行为回归，不证明审美效果或水面背景下的文字对比；实际观感、不同手机色彩与小区域滤镜帧时间仍待验。
