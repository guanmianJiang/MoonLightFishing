# UI材质一致性报告

规格：`docs/design/ui-material-spec.md`。

## 改动与核实范围

- route/toolbar/zoom、提示与搏鱼状态面板统一浅透海盐渐变、柔和边缘光、接触阴影，主按钮受光面与内阴影直接在状态层增强。
- 结算、手记和设置使用高不透明阅读渐变，弱化内部重复底框；不使用祖先opacity，不引入装饰资源或持续动画。
- 核心弹性按钮和SVG未修改；材质层不写尺寸、位置、输入与布局属性，最终布局层仍最后加载，V2禁用/选中/按压保持。
- 新增blur仅限aimCue和toast两个小HUD区域，支持检测及减少动态有回退；未给大面板增加模糊。现有背景效果不属于本轮新增。无新增3D draw call、资源或shader，CSS合成性能尚未实测。

## 验证

- 新增材质测试5项；材质、状态、适配与核心受力显示相关27项通过。
- 全量`npm test`705项通过，构建及资源校验通过。
- 共享工作区新增鱼动画curl字段，原静止对象测试还断言旧4字段结构。本轮仅补全curl:0断言以覆盖静止边界，没有修改该动画实现；全量数量包含其他任务。
- 本轮已跟踪入口/静止断言/IMPLEMENTED差异检查通过；材质spec、规则与清单一致。

## 未验

按用户此前要求，不进游戏、不用Computer Use或浏览器。源码测试不等于视觉验证；水面/沙滩背景下的文字对比、不同设备色彩、实际模态观感和提示滤镜合成成本待验。后续低端真机比较提示出现前后与关闭滤镜的拖动帧时间，并检查窄屏/键盘场景。
