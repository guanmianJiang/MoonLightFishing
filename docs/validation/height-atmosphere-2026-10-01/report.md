# 天际线高度散射验证

版本：`2026.10-height-atmosphere`，日期：2026-10-01。

## 结果与参数

距离雾已替换为海面附近较厚、随高度指数衰减的空气层。天空、倒影、主水面、水膜和普通材质共享同一解析传输与散射颜色；同样路径长度在不同海拔产生不同雾量。水下折射捕获跳过接收面的空气雾，避免主水面重复合成。没有旧 `FogExp2`、独立远水距离平方雾或额外去饱和层。

验证采用当前发布参数：云高度 0.5、雾层高度 22 米、散射强度 1.35、向阳暖散射 0.15、天空 02、旋转 82°。开发期间用户发布了这组值，本轮保留；完整快照见 `published-defaults.json`。规格表中的 12 / 0.45 / 0.15 是模块回退，不能当作当前发布值。

## 性能、边界与未验证项

解析积分没有多步体积采样，不增加贴图、渲染目标、额外绘制或天空纹理查询。普通材质增加世界位置 varying 与少量指数/相位运算，每帧一次可见材质发现遍历。相机 far 从 2400 扩到 16000，利用已有约 12 公里水面，避免近裁剪边界；未增加海面分段。预览显示的 draw=1 仅是后处理最终一次绘制，不作为全场景 draw call 或性能证据。

模型是平面海岸高度层单次散射近似，不含地球曲率、完整多重散射或体积云；80 米极端诊断视角仍受有限海面几何影响。低端手机需默认/关闭各运行等待与环绕 60 秒，记录帧时间和模型切换卡顿；真机 GPU 性能、持续触控及完整 HUD 操作录像尚未验证。六张 PNG 未在本轮修改，其技术门槛与哈希由资源测试核对。
