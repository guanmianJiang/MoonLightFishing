# 岸边基础水位一致性修复

- 日期：2026-10-01；版本：2026.10-shore-level。
- 用户后续截图证明第一轮未修复；原“颜色淡化就是根因”的判断不完整，已撤回原完成登记和视觉结论。

## 可复现根因

主水面顶点来自高度约0的旋转 PlaneGeometry；交互网格顶点也以0为基础。旧实际顶点表达式 p.y+=waterSurface(...).z+lift 漏加0.14米。岸线抬升和海床按0.14米计算，沙地还被压到0.14+波高-0.045米。接触点的旧实际水面比沙地低0.14米，近岸 waterDepth 被钳制为0，反射深度门槛也随之关闭。AlwaysDepth 仍把水合成画在沙地之上，因此看起来是整条裸沙色水带，alpha=1 并不能证明几何正确。

本次将共享 WATER_LEVEL=0.14 生成同一 GLSL 常量；实际顶点、接收面和沙地全部用该基准。主水面与交互水面使用同一顶点着色器，保留相对波位移和弯月面抬升，不通过对象 position.y 再加一次。小船旧浮动也按0水位，纠正水位后发现船舱进水，已同步小船初始化/浮动的相对高度，并复核最终实画。
