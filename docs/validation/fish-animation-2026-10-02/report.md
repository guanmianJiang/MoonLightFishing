# 鱼身与动作复核 · 2026-10-02

## 实现与一致性

- 规格：`docs/design/fish-animation-spec.md`、`fish-asset-anchor-spec.md`。驱动器输入真实鱼种/重量和搏鱼 effort/surge；动作不写鱼距、张力、胜负或存档。
- 新驱动在靠钩、咬实、搏鱼、出水、托举、放流、游离以及图鉴统一积分相位。GLB 异步替换继承驱动器，旧实例退出时恢复共享几何并释放自有缓冲，再次使用可重新绑定。
- 六鱼种改用 32×24 圆润鱼身和平滑法线；小银鱼侧纹贴合身体。GLB、PNG、源 blend、manifest 由原生成器同源导出。鱼鳍和老金鱼缺尾保留，嘴锚位置不变。
- 七种原资产与新资产的 GLB primitive 数一致：鲤鱼16、白条18、鲈鱼24、鲶鱼20、老金鱼15、月鱼17、虾24。没有新增 draw call、shader、纹理或渲染通道。实际动态顶点示例：鲤鱼1190、白条1314、虾675，仅当前可见实例更新。

## 未验证与限制

水下鱼体可读性仍受当前折射、水深与远机位影响，连续摆动通过近景帧与真实挂点测试验证；没有据静态截图宣称每一帧都清楚可见。真实手机触感、低端GPU/CPU持续帧率与长时内存尚未测试：建议低端安卓连续搏鱼60秒记录帧时间和 draw call，再连续20竿检查几何内存是否稳定。声音与振动本轮沿用原事件调度，没有新增触发点。
