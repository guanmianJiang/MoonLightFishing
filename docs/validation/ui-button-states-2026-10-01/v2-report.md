# 按钮状态与比例V2

规格：`docs/design/button-states-spec.md`的V2部分。

- hover使用材质各自的提亮/加深面色、边线及2px抬升；仅fine hover设备适用。
- 选中使用中浅绿色、明确内沿与边线，hover保持选中材质；按压表面压暗、下沉3px并压缩侧沿。次级入口有独立hover/pressed反馈，禁用排除仍有效。
- 瞄准抛竿不再占满剩余横向空间，宽度160至248px并允许收缩，高64px；取消80×56px。图标30px、抛竿文案18px，删除图标小底框。镜头入口48×56px，缩放组48px外宽容纳44px子按钮及边线/内边距。
- 不修改游戏逻辑、核心四向弹性输入、footer安全区或3D资源。没有新增持续动画或shader成本。

验证：按钮状态模块9项、含核心手势相关24项通过；全量596项通过、构建资源校验通过。共享工作区其他任务也在更新，新增全量数量不全部属于本轮。最终细化次级状态选择器优先级后再次检查状态模块与全量构建。

按用户要求未进入游戏，也未使用Computer Use；源码/规则测试不能替代实际视觉和真机触控验收。低端设备快速交互帧时间、极端文本及窄屏真实布局待验。
