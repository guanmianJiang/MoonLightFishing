# 分辨率适配一致性检查

规格：`docs/design/responsive-ui-spec.md`。日期：2026-10-02。

## 发现与改动

原分散布局以浏览器viewport断点判断，但game可限宽；主按钮vw参照错误、横屏/短屏footer规则会改为窄栏、body设置面板可脱离游戏画幅，旧弹窗不感知键盘可视高度。本轮新增实际game尺寸Observer与纯布局计算，统一最后布局层，并通过visualViewport限制body弹窗及设置。

窄屏/短屏按实际画幅切换；减少次级留白，详情/底部/结果内容可滚动。鱼饵保持44px最小宽，极端宽度可横向滚动；124px搏鱼输入与连续几何不缩放，不修改手势门槛。安全区仍由CSS env读取。横屏仅兼容，不扩张为横版设计。

## 验证

- 新增5项测试：320×568、360×640、390×844、430×932、桌面实际窄画幅、280×390短画幅，非法/零尺寸，Observer与无Observer回退，可视键盘高度/偏移，重复样式写抑制与清理，真实CSS加载及触控/滚动约束。
- 29项适配、状态和核心输入回归通过；最后细化样式/重复属性写入后，全量`npm test`689项通过，`npm run build`及资源校验通过。入口/接线等本轮已跟踪修改文件差异检查、布局模块语法检查通过。
- 共享工作区新增haptics调用导致原VM手势测试缺少fightHapticStrength；测试helper补入真实模块函数后恢复通过，未修改游戏触觉行为。
- 原规格、业务事件、V2状态和本轮布局对应；IMPLEMENTED新增条目。全量数量包含其他工作区任务，非本轮新增数量。

## 未验

遵循用户此前要求，不进入游戏、不使用Computer Use或浏览器。模拟DOM/规则测试不能证明实际布局、视觉和手感。真机地址栏伸缩、刘海、长文本、键盘焦点、场景重排后的拖动与低端快速交互帧时间待验。没有新增3D资源、shader或逐帧DOM测量。
