# 核心操作按钮风格修订验证

日期：2026-10-01。范围：独立设计样例与规划修订，运行游戏业务代码未替换。

## 修订结果

- 初版圆盘、同心圈、轴心、摇柄及悬空提示底板被否定；现已移除。旧报告 `docs/validation/reel-control-design-2026-10-01/report.md` 仅记录旧方案，不作为当前视觉验收依据。
- 暖杏色、软方倒角、上缘和底侧复用现行抛竿按钮的视觉语言。入口内直接显示按住/收线、正在/让线、线紧/松手或等待；常态不再在按钮外重复操作动词。
- 条件提示紧贴固定按钮上方，无额外卡片底板。短直条只表达鱼线受力，不表示胜率或上岸进度。样例没有永久旋转动画。
- 场景底图由现行3D场景生成的独立fixture截图取得，不读取玩家存档；隐藏旧搏鱼摘要与旧控件，避免静态背景与演示状态互相矛盾。生成工具 `tools/create-reel-design-scene.mjs` 使用相对路径；临时预览文件不交付到运行入口。

## 测试与一致性

`node --test tests/reel-control-prototype.test.mjs`：6项通过、0失败，见 `prototype-tests.log`。执行真实样例脚本，覆盖主动作内置、按压深度、条件提示、提竿衔接、危险优先、42px机会门槛、24/10px让线回中、横向容差、第二指针、cancel/失焦与模式清理。

规格、样例与总清单已同步为修订草案；旧视觉不再推荐。运行DOM、物理、存档、声音与触觉未修改，因此不把当前项目全量构建当作本设计的完成证据。

受力为固定演示值；横向调竿短句、真实accepted反馈/鱼距收益、拇指遮挡、safe-area、完整真机上下划和低端设备响应均未验证。完整场景截图用于构图判断，不能证明真实游戏里的反馈时序或手感。
