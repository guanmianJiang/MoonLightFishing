# 远景天空倒影扭曲控制

## 诊断与实现

截图中变形的是水面的云倒影。源码证实旧法线影响只调宏观法线与完整法线的插值，不能削弱宏观波浪；宏观波浪也未按相机距离收敛。掠射视角下反射方向对法线很敏感，可能把云形拉成宽长带。截图无法单独确定每个像素是否同时受到SSR或地平线方向回退影响，本轮不声称已复现实画。

长波扭曲默认0.35，细波使用原保存的reflectionNormalStrength；远处扭曲保留默认0.15。距离20m以内保持近景强度，20–100m平滑衰减，100m之外保持设定比例。缩放坡度后归一化，统一用于Fresnel、天空和SSR；岸边弯月面维持独立原有控制。几何波浪、折射、太阳高光、天空采样和大气未调整。旧存档补缺省值，不覆盖已有其他参数。
