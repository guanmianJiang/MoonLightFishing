# 天空与雾参数验证

版本 `2026.10-atmosphere-controls`，2026-10-01。规格见 `docs/design/atmosphere-settings-spec.md`。

## 结果

画面设置提供天空雾强度、场景雾强度、远水雾密度，各为 0–2，可分别关闭；“全部去雾”只将这三项置零。天空另有云层高度倍率 0.25–2，小值降低云的位置；水平旋转继续改变可见云的方位。发布默认高度 0.5、天空雾 0.25、场景雾 0.35、远水雾 0.35。既有其他调色参数与天空 02 / 82° 默认保留。

默认天空最大额外散射仅 0.04；普通物体雾密度 0.0004375，雾天气 0.00098；默认远水在 200 / 400 米雾量约 3% / 12%，倍率 1 可复现上一版。雾 0 时没有强制下限，天气切换不能重新打开对象雾。云层映射保留赤道与极点，高度大于 1 也能到达均匀极区，避免采样中部造成天顶经度接缝。

## 浏览器验证

使用 `tools/create-atmosphere-preview.mjs` 创建临时页面，加载真实 `createWorld`、真实画面设置和项目全部样式；独立测试端口、本地画面参数保存。无存档写入逻辑，发布默认按钮禁用。场景水波固定为 8 秒，等待/收线是渲染状态夹具，不能替代完整游戏操作录像。临时页面完成验证后移除。

- 点击“全部去雾”、刷新、重新打开设置：三项滑杆及数值均为 0，云层高度仍 0.5；切到雾天，页面显示对象雾密度 0.0000000。
- 恢复默认：三项恢复 0.25 / 0.35 / 0.35，天空 02、旋转 82°、高度 0.5。数值输入和滑杆同步；输入远水密度 3 不覆盖有效设置，离开输入框恢复 0.35。增加 `onblur` 恢复，覆盖直接输入与触控离开。
- 新增数值框、滑杆和去雾按钮触控高度至少 44px；设置内部可滚动，保存/恢复固定可及。390×844 为主，320×568 小屏参数/场景及 844×390 横屏场景兼容截图已保存。
- 六个天空使用同一参数和 0° 朝向检查。82° 等待视角主要对着云间空隙，降低雾不能制造云；水平旋转配合高度可以将现有云带入视野。天空与倒影同步变化，云色可能形成较浅倒影，这与空气雾独立。
- 晴天、雨后、雾天、默认/无雾与上一版浓度对照已保存。浏览器未记录 shader 错误或警告。

## 一致性与未验证项

规格、发布默认、字段范围、面板输入、uniform 与发布接口使用同一四字段契约；旧参数保存记录保留，新增字段缺失采用默认。旧天空/减雾对照工具已适配新的水雾函数参数和每帧对象雾更新，避免基准雾密度被覆盖。

没有增加贴图、draw call、render target 或纹理采样，新增少量纬度标量运算、雾距离倍率与每帧一次对象雾密度赋值。完全去雾可能显露极远水/天空的颜色差异；不自动加回雾。低端移动设备帧时间、峰值内存、完整连续触控垂钓录像和极端自由镜头仍待真机验证：建议默认与无雾各环绕/垂钓 60 秒，检查远水边界和天顶接缝。
