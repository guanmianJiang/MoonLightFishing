# 钓获展示层次与主动作触感验证

日期：2026-10-01。版本：`2026.10-catch-reveal`。规格见 `docs/design/coastal-ui-spec.md` 的“钓获揭晓与主动作反馈”。最终实现以排版、真实模型和按钮反馈表达收获，不使用新增装饰位图、金边星芒或循环扫光。

## 最终实现

- 标题和身份同一行，真实3D鱼体放大；鱼名与真实搏鱼评级组成独立一行，重量长度在其下。评级不再混入属性栏，也不与可折叠的鱼体绑定。选择一个建议、其他操作按需展开及原显式处理流程继续保留。
- 结果面板轻移260ms，鱼体显现360ms，成绩呈现280ms延迟80ms。按钮第一帧可操作，不等待动画。`data-reveal` 只在新打开时设置，存档恢复为false；重复渲染不触发新声音。减少动态偏好关闭这些入场动画。
- 暖杏主动作提供上表面、柔和边缘、5px侧面与接触阴影；按压下移4px并轻缩，130ms复位。选落点、确认抛竿、建议处理和继续垂钓共享该材质；准备主按钮图标与文案纵向排列，确认抛竿仍横向排列。无循环呼吸或扫光。
- 320结果鱼体区110px、标题身份并排，让详情入口与主操作完整可见。展开其他操作时收起鱼体及重复页头，保留鱼名、评级、属性和详情；选择区独立滚动。图标和评级不接收pointer，未改动112px搏鱼输入区、物理、奖励或存档。
- 不新增运行图片、Three.js对象、纹理、shader或更新循环。此前未采用的装饰文件及运行引用已经移除，构建没有该资源路径警告。

## 一致性与未验项

规格、纯展示输出、结果DOM、入口触控尺寸及源码反馈时长一致；`docs/IMPLEMENTED.md` 已同步目标、P0、依赖、测试和版本。所有仓库资源与文档引用使用相对路径。

本轮浏览器使用恢复中的原钓获检查版式，因此实际新上岸后的短入场未录制成连续视频；开场标志与音效的一次性由自动测试验证，不能用静态截图宣称动画或真实手机触感验收。不同鱼种、挂物与追踪文案由纯函数验证，未逐一捕获实画。

真实手机按压触感、系统安全区和地址栏伸缩、低端手机十分钟连续垂钓的帧率与内存仍待实机核对。本轮不涉及复杂渲染改动；结果显示依然复用既有模型预览渲染器。
