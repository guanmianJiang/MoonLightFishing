## 接入结果

- `src/index.html` 的实际 `#fightControl/#fightHold` 已替换旧线轮、两行常驻说明、方向箭头和底板。固定124×124输入节点不随表面移动；148×148右下区读取safe-area。暖杏连续表面、60px钓钩浮雕、局部受力弧和短确认复用已审阅V7设计。
- `src/reel-surface.mjs` 与已审阅样例保持同源几何，`src/ui/reel-surface-view.mjs` 负责展示与420ms回弹。`src/app-final.js` 从实际手势传入dx/dy，使用真实机会、负载和 `pumpRod(...).ok` 更新反馈。没有修改鱼距、物理门槛、存档或声音/触觉收益。
- 接线检查发现旧逻辑会先标记lifted再调用引擎；本版在引擎拒绝时撤销假抬竿并恢复收线，确认只在成功后出现。实际pointercancel/lostcapture/失焦/页面隐藏会清理按住状态、收线声音、确认和展示回弹；新触控接管回弹、第二触点不能接管真实手势。
- 咬稳提竿同一触控延续到持续收线；挂物仍立即点按收回。抬竿后滑回中位、下压后回中、四向和斜向调竿保留既有42/30/24/12/10门槛。
- `src/reel-surface.css` 位于旧样式之后，明确限定 `data-surface="elastic"`，清除旧底板和按钮位移/滤镜。HTML提供显式初始几何与渐变，避免缺失可选样式产生黑盘。旧详细动作词保留aria-label/隐藏节点，视觉只有必要短纠错。

## 离线视觉与性能

`tools/render-reel-surface-runtime.mjs` 从实际 `src/index.html` 的SVG以及运行展示控制器取得路径与属性，加载实际钓钩资源，离线生成 `runtime-states.png` 九状态与 `portrait-320.png` / `portrait-390.png` 构图。检查了提竿入口、按压、四向/斜向、危险与回摆归位的连续侧沿、图标比例和固定位置。SVG原件见 `runtime-left.svg`。

构图使用旧样例静态3D背景；这是运行UI资源渲染与静态合成，不能作为当前游戏镜头、浏览器CSS级联或手机实画证据。遵照用户要求没有Computer Use或替代桌面/浏览器自动化。

没有新增3D对象、纹理、shader或WebGL上下文。正常搏鱼复用既有RAF，静态几何不重复计算/写路径；独立释放动画最多420ms，取消及减少动态时立即终止。低端手机仍须验证连续拖动、快速重按、危险/机会切换下的帧时间与输入延迟。
