# 上鱼后的动画复核 · 2026-10-02

## 修正与来源

正常搏鱼胜利原来因为 `landedFromFight` 跳过承重提拉，只保留举竿姿势；鱼离水后仍以弱小、连续的全局正弦摆动展示。现在保持举竿衔接，叠加一次按重量变化的承重与卸力；真正离水后启动三次逐渐减弱的收腹、甩尾和松回。头部及鱼嘴保持锚定，身体和鳍共用变形。约1.55秒后安静展示。

另外修正正式模型迟到时一直沿用备用鱼的问题：搏鱼及上岸引用共同交接，保留鱼嘴世界坐标、尺度、姿态、可见性和摆尾相位，释放旧实例变形几何；旧竿和已处理结果的迟到加载不接入。

## 自动验证

- 本轮新增8项测试：三次脉冲及间隙、重量/坏输入/30–120Hz时间采样、减少动态、悬挂朝向、正常胜利承重、实际场景离水门槛与重置、模型交接与相位、迟到加载及旧竿隔离。
- 七种实际GLB回归加入最大0.18鱼长收腹，检查法线、包围球、嘴锚、缓存和实例释放。解析变形导数也与数值导数对照。
- 当前共享工程 `npm test`：718项通过，0失败；`npm run build`：123模块，构建及资源检查通过。数量包含其他并行任务已有测试，不将其记为本轮新增。

## 浏览器复核

使用 `tools/create-landing-animation-preview.mjs` 生成一次性真实场景快照，只加只读观察接口和可见复核按钮，使用60Hz受控时间逐帧推进；生产游戏没有此接口。复核服务器停用HMR，防止共享源码改动重置中间动作。下面截图均在最终代码和正式鱼模型交接修正之后保存。

- 390×844大鱼：提拉0.60秒尚未完全离水；1.20秒时离水0.22秒，首次收腹/甩尾活跃；1.40秒处于安静间隙；2.50秒基本收稳。正式模型已到位，钩点与嘴连续。
- 320×568小鱼：离水0.20秒首次短促动作；鱼嘴朝上，人物、鱼及线仍可见。瓶子未启动离水挣动事件，悬挂无活体收腹。
- 844×390仅做同一动作的横屏兼容检查，未作为主构图设计。
- 隔离存档的固定生产构建：实际点按选点/抛竿、触控提竿及收线，银背鲫0.34kg成功上岸，经过展示进入结果；点击“做成记录”后回到下一竿，轮次剩余3竿。声音按钮可切到“开”，本轮没有测量声音输出。
- 三个复核页面控制台均无错误或警告。

## 性能与未验证项

没有新增模型、材质、纹理、shader、渲染通道或draw call；沿用现有可见鱼体CPU变形和水花池，三段脉冲为固定小表，离水检测复用Box3。更大变形的包围球预留已由实际GLB验证。

低端安卓连续20竿的帧时间、几何内存、真机手感和减少动态的实际观感待验。本轮未改变音效或振动，未声称验证手机扬声器或震感。

## 一致性

规格、场景调用、鱼体驱动及测试一致；展示时长仍为3.2秒，胜负/奖励/处理逻辑未改。旧接口调用保留原行为，新场景明确传入离水年龄。异步替换保持年龄和相位，杂物零活体动作。共享工作区的其他功能改动保留。
