# 倒影几何一致性复核

本轮替代reflection-distortion版本的距离压平处理。水面不再按20–100m距离弱化长波反射法线，删除reflectionFarRetention字段、uniform、提示与默认合同；旧保存/发布中的此字段不进入当前设置。长波法线倍率缺省1，已有显式保存的倍率仍保留。倍率降低明确为美术调整。细波的原有滤波未改，不能宣称所有波频率都已完成物理采样。

源码核实：天空通过reflect方向采样全景；岸边物体SSR用无水主相机颜色/深度捕获，capture原样renderer.render(scene,camera)，未创建平面反射镜像相机。捕获有一次场景绘制成本，SSR最多12步+3次细化+一次命中色，未增加预算。屏幕外物体、波面遮蔽、多次反射不具备真实光线追踪能力，向下射线仍有地平线代理回退。

实际GLSL标量函数与Three向量测试验证长波倍率1保存梯度、反射等角和长度、退役参数无uniform、旧合法调整保持及捕获原相机接线。相关49项通过，见related.log。全量567项中566通过，1项结果弹窗用例报reelSurface未定义，见tests.log；此用例及业务文件非本轮修改，未登记全量通过。构建及资源校验通过，见build.log；构建不等于GPU编译。

算法/参数/文档一致：未新增距离阈值、查询、模糊或反射相机；历史距离控制章节保留并标注已替代。按用户要求未操作界面，未登记长条倒影已消失。待验证：固定9:16相机和波相位下比较长波倍率1/美术减弱，检查近远水、云映射、海天线及SSR边缘；低端真机各60秒记录GPU帧时间/内存和闪烁。进一步物理化需核验已解析波频率和真实像素足迹、未解析坡度方差BRDF及遮蔽，不用独立相机距离规则替代。
