# 搏鱼提示归组与示意比例修正

日期：2026-10-01。规格：`docs/design/coastal-ui-spec.md` 中同名条目。

## 原因与修正

原布局将实时示意拆出摘要，SVG以非等比例方式压缩，岸边为整块填充色、方向说明绝对定位在图外。最新反馈中的鱼被压成点、文字散在水面，来自这一布局。截图为局部裁切，不能据此断言整个卡片在真实视口被顶部裁切。

现在动作图标/文案、真实竿线示意、风险与方向都在 `.fight-summary` 中。SVG等比例显示并扩大鱼形；岸边改为锚点和短线。风险固定左侧、方向固定右侧，平稳状态也不受旧的右对齐规则影响。正常示意40px、窄/短屏38px；卡片约111–115px高，顶部12px加安全区。抬竿复查发现右上卡片挡住上升竿尖，最终常规竖屏改为左上190px宽，搏鱼时收起湾名；窄屏保留湾名和右上卡片，横屏保留旧摘要兼容。原112px收线手势、连续指针捕获、搏鱼数据及物理逻辑保留。

## 一致性与未验证项

本规格明确替代历史“示意拆出摘要”布局；旧版本记录保留，其布局不能再作为当前标准。没有新增位图、3D对象、纹理、shader或绘制通道。验证为桌面浏览器手机尺寸；持续长按/滑动组合、极端镜头下全部鱼种竿弯的遮挡、真实安全区和低端手机帧率仍待实机验收。仓库已有鱼篓售卖升级与HANDOFF的方向差异不在本次修改范围内。
