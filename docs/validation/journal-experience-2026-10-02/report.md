# 图鉴手记一致性检查

规格：`docs/design/journal-experience-spec.md`。

## 已实现

- 主入口为手记/图鉴/收藏，带真实成果计数；技巧/钓组/鱼篓/鱼市通过原生details展开，保留原操作入口，不新增经营功能。
- 默认手记先呈现成果、下一竿准备、最近相遇与收藏入口；原水域履历、目标、观察、追踪/生态移入可展开区域。点击成果进入对应图鉴或展开水域详情，使用白名单跳转并重置滚动；展开详情定位到该区域。
- 图鉴的已遇状态来自已有日志、收藏、追踪、合法搏鱼报告与水域履历；未知鱼种不加载图片、不披露名字，已遇条目展开习性、已有重量/地点/评级。新档空状态给出首次收获方向，未结算pending不算成果。
- 下一竿按钮复用原prepareSpotPlan，pending时不显示；该流程保留显式瞄准/抛竿步骤。图鉴不占收藏位、不改存档、不发探索奖励；日志有界，不能承诺已遗失历史永久留存，界面明确说明。
- 不修改核心输入/3D画面，不加新纹理或持续动画；仅复用已遇鱼现有缩略图。减少动态偏好仍沿用原换页逻辑。

## 验证

- 8项新增测试覆盖新/缺失档、多来源去重、放回收藏后现存履历、chronicle证据、非法ID/重量/评级、pending排除、观察状态、转义/图片协议、原页面保留、实际导航白名单与CSS触控布局。
- 相关32项通过；全量727项通过，构建及资源校验通过。共享工作区其他改动也存在，全量数量非本轮新增数量。
- 最后加入详情滚动定位后，24项手记/履历回归、全量727项及构建再次通过；本轮已跟踪文件差异检查通过。规格、代码、数据来源和IMPLEMENTED对应；正文与图鉴在原bookContent滚动，最终分辨率层未改。

## 未验与限制

沿用用户要求未进入游戏，未使用Computer Use/浏览器。本轮源码测试不能证明实际审美、手记阅读效率、屏幕阅读器朗读效果、长文本及低端手机缩略图/滚动帧时间。全部成果展示来自现有保存证据，不补造旧逐竿历史，也未新增永久图鉴存档字段。
