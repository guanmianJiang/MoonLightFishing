# 按钮情境引导与确认验证

版本：`2026.10-action-guidance`。对应规格：`docs/design/coastal-ui-spec.md` 的“贴近按钮的情境引导与确认”。

## 本次实现

- 钓获推荐不再有右上角“建议”小字。原约定说明区成为指向下方主按钮的轻提示，说明当前动作；匹配有效未完成目标才说明推进约定，次行保留真实目标与进度。容量/挂物回退不假称推进原目标，原处理名称、后果和所有替代动作仍在。
- 换饵后短提示对准真实选中按钮，按钮亮度仅短促变化一次；换钓点/取消提示指向下一步选落点。确认2400ms后退出，替代顶部重复的“已就绪”通知。首竿、同水域同鱼饵追鱼影、瞄准、已调整落点、排队抛竿由真实状态驱动。
- 工具条下的提示与原鱼饵说明二选一，提示与尖角不接收pointer。上方选点卡只显示水域/落点信息，操作引导位于确认按钮旁；开始垂钓后底栏和新提示均退出。
- 所有逐帧更新按展示键去重，重复刷新不重启动画或live播报；切换取消旧动画，减少动态偏好保留完整文字。结果指向动效只有实际新揭晓才播放，存档恢复仍安静。已有等待/鱼口/搏鱼反馈继续使用原逻辑。

## 一致性与未验证项

- 规格、纯展示函数、应用接线和测试一致；展示不写存档、不自动抛竿/处理，不改奖励、鱼池、追踪、容量、搏鱼胜负或手势物理。两步抛竿保持：进入选点后仍由玩家确认。
- 本改动未增加位图、Three.js对象、纹理、shader或draw call，短动画只作用于小范围DOM。减少动态路径以单测验证；未修改系统设置。
- 实画中的已调整反馈由路线选点触发。真实手指精确点水面、拖动连续调整、长按搏鱼、低端移动设备帧率/触感、动态偏好在真机上的表现和全流程入场录像尚未验证，不能凭截图宣称完成。
- 旧规格中的深色底板与静态推荐标记已由后续规格替代。HANDOFF与既有经济模块的产品分歧保持原记录，本轮未改该模块。
