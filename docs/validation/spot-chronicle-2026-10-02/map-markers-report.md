- 三个钓点共用同一纯视图。配置只写可尝试观察的地点特征；短状态来自该点此版最后一竿合法结算。锁定优先，旧档不会被显示成“从未到访”。点选仍只走原有切点与准备摘要，确认抛竿独立。

- 不增加场景对象、纹理、shader、逐帧动画或存档字段；新 DOM 仅为每点一个符号和状态文本。
