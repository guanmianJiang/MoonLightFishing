# 落点手势与入水交接验证（2026-10-02）

## 实现与规格

先更新 `docs/design/cast-landing-flow-spec.md` 和 `docs/design/fishing-loop-spec.md`，再改落点换算、镜头手势、抛投淡出与实际场景。近水／中段／远水仍是快速选择；水面按下不会抢走已有落点，轻点松手才选定，拖动过 7px 后依据按下时的落点和固定摄像机下的水面位移微调。第二指切入中止本次微调，允许缩放。确认后复用两枚落点网格，到浮漂飞行末端渐隐；飞行和水花继续使用 `pending.castPoint`。

## 一致性与未验证项

落点范围沿用原水域和岸线规则；入水目标、竿数与随机结果未增加新来源。仅在约 1.8 秒抛投阶段让现有的光圈与中心点继续显示，最多临时增加两次 draw call；不增加网格、贴图或 shader，摄像机仅在手势开始复制一次。

桌面浏览器鼠标不能替代多点真机触控。低端 Android 设备仍需以 9:16 竖屏完成点选、微调、双指切入、快速取消与重复抛投；记录帧时间和 draw call，比较准备态与蓄力阶段，检查 20 竿后内存和掉帧。横屏本轮只按兼容性保留，不作为主构图验证。
