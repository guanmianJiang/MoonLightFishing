# 钓获处理反馈验证（2026-10-02）

## 实现与一致性

- 规格：`docs/design/catch-process-feedback-spec.md`，并与捕鱼主循环及结果音画规格交叉引用。
- 放流取消缓入缓出的浮动轨迹，改为 11.8 m/s² 解析重力。质量只增强冲击，不改变下落加速度；接触点的位置/速度连续，水下阻力先消耗下落动量，再转为活鱼游离。杂物仅下沉，不摆尾、不播放活鱼旋律。
- 关闭结果窗前接管同一个模型和实际位置，保留尺寸、材质。恢复钓获使用已加载模型或缓存替身，并以手部世界坐标起步；大鱼处理延续站姿。相机从原取景衔接，下落时适度拉开并转向鱼体/入水点，最后平顺回到准备视角。
- 每次选择立即计账保存一次；1.85 秒放流 / 1.25 秒其他动作只为展示。期间隐藏准备入口，最后一竿回顾等动作完成。后台结束瞬态展示，旧计时器不重播或重开回顾。容量不足保留原结果窗。
- 提示根据真实结算说明记录、收藏、入篓、放回及追踪状态；发现文字优先。旧线索计时器不再覆盖结果，放回杂物的标题不再叫“新收获”。小屏提示允许换行。
- 放手声从 whoosh 音源 0.20 秒处播放；水声从 splash 音源 0.12 秒处播放，避免截取静音前导。实体入水声、水花和短振动共用同一个水面接触事件。普通接触 12 ms，大重量接触 [20,22,8]；不支持振动时照常呈现声音和画面。
- 处理开始取消上岸展示旋律尾音。恢复钓获首次点选从触控启动声音；HTML 回退短片段在实际播放开始后计时，启动超过 250 ms、静音/后台/结果替换即丢弃。主动取消不再误报播放错误。

## 风格、性能与待验

沿用现有温暖海岸、模型、光照和水体；没有新增滤色、闪白、全屏效果或 shader。处理复用当前钓获、水花池及缓存模型，未增加常驻渲染物。精确弹道采用绝对时间采样，帧率波动不累积重力误差；晚超过 180 ms 的水面事件丢弃声音/振动，防止恢复后台后错拍。

**未完成真机验收**：浏览器 PCM 不能替代用户手机扬声器、系统静音、触控振动和主观力度检查。低端移动设备应在原有画面设置下连续执行小鱼/大鱼/瓶子处理，比较前后帧时间与 draw call，并连续 20 次处理后检查内存是否持续增长；后台切换、静音、减少动态及设备不支持振动也需实机检查。渲染资产原有外观沿用，本次没有进行资产风格重制。
