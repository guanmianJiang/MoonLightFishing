# 大气颜色与天空倒影算法/参数复核

> 历史记录：本报告中的倒影柔度已撤销。当前采样和验证见 `docs/validation/reflection-no-blur-2026-10-01/report.md`；下方参数/日志保留撤销前版本含义。

版本：`2026.10-atmosphere-reflection-review`。用户要求不调用电脑界面，本轮只读取源码/资源、运行离线数值和测试，没有浏览器操作、截图或本地存档写入。

## 发现与修改

1. 原空气色硬编码 `(0.1812,0.4621,0.6172)`，偏饱和青蓝；当前强度 1.35 在 2 米高度、12 公里水平路径产生约 99.987% 未钳制遮盖，实际钳制 98.5%，几乎把天空选项变成一条固定色带。现在保留高度积分，采用可调 `atmosphereColor`，默认低饱和蓝灰 `#9fb9d3`；向阳项独立加法并保留太阳颜色/光强，不再归一化太阳后忽略天气照度。
2. 原 `max(physical,artistic)` 在基础反射 0、幂次≥5 时总选物理曲线，当前幂次 7.8 实际没有作用。现在幂次直接控制 Schlick 过渡，基础增量 0 保留水界面约 2.04%。默认幂次 5；其他幂次明确属于美术曲线。
3. 原反射强度 1.13 乘权重后钳制，在近掠射角提前变成纯反射。现在 0–1 控制权重、1–2 控制反射辐亮度增益，避免强度改变 Fresnel 曲线并吞掉折射。
4. 原反射只查单点天空，没有独立柔度，并可能将 atan 经度跳变误当巨大纹理足迹。新增倒影柔度，复用已有 mip，先回卷经度导数；一次显式 mip 查询替换原查询。下行且无 SSR 命中的反射使用地平线代理，不再取地下天空。背向观察者的法线不产生满权重镜面反射。
5. 原水面反射额外叠加天空中没有的 64/512 次太阳亮瓣，与原风格化太阳高光重复。删除该两层，保留由真实太阳方向驱动的风格化高光。
6. 原固定增饱和 1.17、RGB 增蓝倍率，以及波面明暗作用于混合后的颜色，使天空倒影二次着色和受光。现在只作用于折射水体，再混合环境反射；海天使用统一的线性空气源颜色。

没有发现 `reflect(-view,reflectionNormal)` 的入射符号、共享天空旋转或 sRGB 纹理解码方向错误，保留这部分。屏幕内物体倒影仍属于有界 SSR，没有扩展为屏幕外镜面场景反射。

## 数值与资源证据

`node tools/analyze-atmosphere-reflection.mjs` 输出 `numeric-review.json`，直接执行实际 GLSL 标量函数，记录当时全部发布参数。该工具不启动游戏、不创建画面，也不写存档。法线像素读取使用当前可用的 Python/Pillow，支持这张 16-bit RGBA PNG；缺少依赖时仅标记法线分布未验证，不影响标量结果。

- 2 m、12 km 水平视线：旧散射 98.5%，新散射 62.933%，天空透射约 37.067%；80 m 同路径的新散射 2.823%。800 m 眼到海面的新雾量低于 7%。
- `N·V=0.4`：幂次 5 / 7.8 / 12 反射权重为 9.657% / 3.862% / 2.253%，控制已经区分；旧 7.8 与旧 5 都为 9.657%（未乘强度）。
- `N·V=0.02`：原权重乘 1.13 后钳制为 100%；新权重仍为 90.588%，额外 1.13 仅作为亮度增益。
- 天空图 1774×887 使用已有最粗 mip 10；柔度 0.25 的最小目标 LOD 0.625；屏幕足迹 8 像素时选 LOD 3。跨经度接缝的 UV 差 0.999 回卷为 -0.001，不误选最粗层。
- 当前法线图 1024×1024；单图归一化坡度 RMS 0.1142、最大 0.8202。主/次幅度 1.67 / 0.97、反射影响 0.19。单图分布不能代表两个旋转/滚动层的合成或真实镜头，未据此擅改法线与速度。

## 性能与未验证

未新增 draw call、捕获目标或贴图。使用已有天空 mip 链，不额外分配 GGX 预过滤资源；加入少量导数/LOD 运算。所用 `texture2DLodEXT` 在本仓库 Three.js 中映射到 WebGL2 `textureLod`，查询尺寸使用 `textureSize`；本项目原渲染器已经以 WebGL2 为基线。

大气源颜色是受控的高度层近似，未计算全光谱/地球曲率/多重散射；天空 mip 是普通图像 mip，不是 GGX 预积分。SSR 捕获/遮挡仍有屏幕空间近似限制。按照用户要求，本轮未启动浏览器或操作电脑界面，因此新 shader 的实际 GPU 编译、颜色观感、云倒影动态稳定性、完整触控与低端真机帧率尚未验证，构建成功不等于 GPU 视觉验收。后续真机应默认/关闭散射分别运行 60 秒，并检查柔度/法线/天空旋转接缝与太阳高光。

算法参考：[Bruneton 分离 Rayleigh/Mie 与大气传输](https://ebruneton.github.io/precomputed_atmospheric_scattering/atmosphere/functions.glsl.html)、[PBRT 相位函数](https://pbr-book.org/4ed/Volume_Scattering/Phase_Functions)、[PBRT Fresnel 介质反射](https://pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF)。参考完整模型的组合关系，不宣称本项目实现了完整行星大气或微表面积分。
